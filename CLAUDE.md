# LexML parser for non statutory documents

## Folders structure

- docs: capture .md (markdown) documents, mostly describing the development plans and development logs. All files here shall have the YYYYMMDD_HHMMSS_ prefix, defined according to the `date` command output.
- lexml: contains LexML schema.
- samples: includes sample .docx files used for tests.
- tests: stores all the test scripts created through the development cycles.
