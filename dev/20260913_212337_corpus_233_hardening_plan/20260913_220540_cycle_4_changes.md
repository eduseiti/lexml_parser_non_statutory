## Minor changes

### m-1 — `_run_pytest` forces `--color=no`

| Field | Content |
|---|---|
| **What changed** | `tests/regression/test_bare_checkout.py::_run_pytest` |
| **Before → after** | `[sys.executable, "-m", "pytest", *args]` → `[sys.executable, "-m", "pytest", "--color=no", *args]` |
| **Why** | Plan §1.7. pytest colourises when it believes it writes to a terminal; the escapes land exactly where this module's two string parsers look, so both failed falsily and three tests went red on a healthy run |
| **Blast radius** | The subprocess's stdout only. `bare_run` is consumed by five assertions in this module and nothing else in the repository parses pytest output — `test_bare_checkout.py:172` is the only subprocess pytest invocation in `tests/` or `scripts/` |
| **Plan impact** | None. This *is* the plan's stated deliverable and its verified remedy |

Placed in the function rather than at the call site so a future caller cannot
omit it.

### m-2 — `_count` and the two skip filters tolerate ANSI colour

| Field | Content |
|---|---|
| **What changed** | `_count`; the skip-line comprehensions in `test_skips_carry_the_probe_diagnostic` and `test_the_nested_assertions_are_the_ones_that_skip`; new `_strip_ansi` helper and `re` import |
| **Before → after** | Raw string matching → matching on a colour-stripped line. `_count("…\x1b[1m509 passed…", "passed")` returned **0**, now returns **509** |
| **Why** | Spec N-2: `--color=no` governs only what *this* harness asks for. Tolerant parsing additionally survives `PY_COLORS=1`, a pytest default change, or a future caller bypassing `_run_pytest` — the two defend different things and neither is sufficient alone |
| **Blast radius** | Strictly additive in effect: every string that parsed correctly before parses identically after (pinned by `test_count_reads_a_plain_summary` and `test_count_is_absent_safe`). Verified independently by running the module with `PY_COLORS=1` forced on — 15/15 pass |
| **Plan impact** | None. The plan asks for `--color=no`; this is defence in depth beside it, recorded as a spec decision rather than a plan amendment |
