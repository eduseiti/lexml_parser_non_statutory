## 2. Reconciliation — plan vs. reality

### R-1. The `generic` catch-all profile is already delivered (scope overlap)

Cycle 8's deliverable list names "`generic` catch-all profile". It landed in
**Cycle 2** as `profile/generic.py`: `base_score=0.05`, no epigraph patterns by
design, registered so `select_profile` never returns `None`. Cycle 3 gave it
`enacting_res`/`annex_res`/`closing_res` (A-3.3).

**Outcome:** nothing to build. This cycle *discharges* the bullet by asserting
what is already true — that every degenerate and non-DOCX fixture profiles as
`generic` and no document is left unprofiled — rather than by adding code. No
new profile is registered. Recorded as amendment **A-8.1**.

### R-2. `segmentation/` vs `segments/` in §3's layout

§3's tree still names `segmentation/api.py` with an `xslt/` subfolder. Cycle 7
delivered `segments/api.py` with `segments/stylesheets/` (**A-7.1**, already
ratified). §3's layout diagram is stale in the same way for `cli.py`, which it
correctly places at package root. No new decision; the spec uses the real names
and the plan's §3 tree is corrected as part of this cycle's plan updates.

### R-3. `validate/rules.py` in §3's layout does not exist

§3 lists `validate/ schema.py rules.py report.py`. Only `schema.py` and
`report.py` were built; the "rules" half of validation is spread across the
emitters' own gates (`render_norma_checked`'s four blockers, the conservation
comparison, `render/ids.py`'s Rule A). Cycle 8 does not build `rules.py` —
there is no rule left without a home, and a module that re-implements checks
five other modules already own would be a second source of truth. Noted in the
plan update, not asked, because no cycle deliverable depends on it.

### R-4. `python3 -m lexml_nonstat.segments` parses flags by hand

Cycle 7's `segments/__main__.py` uses a hand-rolled `--flag=value` loop rather
than argparse, and its unknown-option branch returns 2. Cycle 8's CLI does not
inherit that; the `segment` subcommand is argparse like every other. The
existing module is untouched (see D-3).

### Non-blocking decisions taken here (D-n)

- **D-1.** `cli.py` is one module, not a package. Eight subcommands sharing one
  argument vocabulary read better in one file than in eight; the formatting
  helpers each subcommand needs already live in the packages it calls.
- **D-2.** Warnings live in a new `lexml_nonstat/warnings.py`, not in
  `telemetry/`. Telemetry is §7.4's rule-vs-referee channel with its own
  report; a CLI diagnostic is a different thing with a different consumer, and
  folding them would make `render_report`'s counts include things that are not
  decisions.
- **D-3.** No existing `__main__` is modified beyond its module docstring
  (which is documentation, not behaviour). Their `main(argv)` functions and
  every byte they print stay as delivered.
- **D-4.** HTML/TXT readers live in `ingest/html_reader.py` and
  `ingest/txt_reader.py`, exactly where §3's layout puts them, and export
  `read_html` / `read_txt` alongside a dispatching `read_document(path)` that
  picks by suffix. `read_document` is what the CLI calls, so adding a fourth
  format later is one entry in one table.
- **D-5.** New tests go in `tests/unit/test_cli.py`, `tests/unit/test_robustness.py`
  (§9.1 names this file), `tests/unit/test_ingest_html.py`,
  `tests/unit/test_ingest_txt.py`, `tests/unit/test_warnings.py`, and
  `tests/regression/test_cli_corpus.py` for the 15-sample × all-emitters sweep.
- **D-6.** `dump-tree` prints the hierarchy (`hierarchy/__main__`'s view), not
  the segmentation. The plan lists `dump-styled` and `dump-tree` side by side
  and `segment` separately; "tree" is the hierarchy in every other place the
  plan uses the word.
- **D-7.** The CLI never consults the referee unless asked: `--referee` defaults
  to `none`, matching §7.3 constraint 7 and `routing/__main__`'s existing
  default. No CLI test may pass a different value.

## 3. Expanded goals

### 3.1 `src/lexml_nonstat/warnings.py` — the structured-warning channel

```python
WARNING_CODES: tuple[str, ...] = (
    "annexes_not_written",     # bundle had annexes and no -o directory
    "emitter_unavailable",     # nested asked for, capability absent
    "statutory_fallback",      # norma asked for/routed, fell back to generico
    "invalid_output",          # emitted document failed schema validation
    "low_confidence",          # routing confidence below LOW_CONFIDENCE
    "flat_fallback",           # hierarchy came back flat (no structure found)
    "incomplete_urn",          # metadata could not produce a complete URN
    "unreadable_source",       # a file in a multi-file run could not be read
    "empty_document",          # the source produced zero blocks
)

LOW_CONFIDENCE = 0.60

@dataclass(frozen=True)
class Warning:
    code: str
    detail: str
    source: str | None = None
    def __post_init__(self): ...        # asserts code in WARNING_CODES
    def to_dict(self) -> dict[str, str | None]: ...
    def format(self) -> str:            # "warning: <source>: <code>: <detail>"

def collect_warnings(model, rendered=None, *, report=None,
                     requested_emitter="auto", wrote_annexes=False) -> tuple[Warning, ...]
```

`collect_warnings` is a pure function of already-computed objects — it makes no
decision of its own and computes nothing a pipeline stage has not already
concluded. That is what makes it testable without a document.

**`Warning` shadows the builtin.** Deliberate, and confined: the module is
`lexml_nonstat.warnings`, imported as `from .warnings import Warning as
Warning` only inside `cli.py` and its tests, and the codebase uses no builtin
`Warning` anywhere (verified by grep — §2 R-8). The alternative names
(`CliWarning`, `Diagnostic`) each say less about what the thing is.

### 3.2 `src/lexml_nonstat/ingest/html_reader.py`

```python
def read_html(path_or_text, *, source: str | None = None) -> StyledDoc
class HtmlReadError(Exception)          # subclass of DocxReadError? no — sibling
```

Mapping, chosen so an HTML rendering of a sample reaches the same model shape:

| HTML | `StyledDoc` |
|---|---|
| `<h1>`…`<h6>` | `StyledPara(style="Heading N", outline_level=N-1)` |
| `<p>`, `<div>` with text | `StyledPara(style="Normal")` |
| `<b>`/`<strong>`, `<i>`/`<em>`, `<sup>`, `<sub>`, `<a href>` | `Inline` flags / `href` |
| `<ol>`/`<ul>` → `<li>` | `StyledPara(num_id="ol1"/"ul1", ilvl=depth)` — the shape `hierarchy/tree.py` already reads |
| `<table>`/`<tr>`/`<td>` | `StyledTable`/`StyledRow`/`StyledCell` |
| `style="margin-left:NNpt"` / `text-indent` | `indent_direct` in twips (1pt = 20tw) |
| `<br>` | splits the paragraph, as Cycle 1's soft break does (A-1.2) |
| `<script>`, `<style>`, comments | dropped |
| `<s>`/`<strike>`/`<del>` | dropped when `drop_strikethrough=True` (Cycle 1 parity) |

Text goes through `normalize_text` — the same NFC + whitespace collapse Cycle 1
applies, so an HTML and a DOCX rendering of one document cannot differ by
normalisation.

### 3.3 `src/lexml_nonstat/ingest/txt_reader.py`

```python
def read_txt(path_or_text, *, source: str | None = None) -> StyledDoc
```

Blank-line-separated blocks become paragraphs; a run of leading spaces becomes
`indent_direct` (4 spaces ≈ 1 tab ≈ 720 twips, so `indent_direct = 180 *
n_spaces`, matching Word's default tab stop). No styles, no tables, no
inlines beyond plain text — a text file carries no typography, and inventing
some would be fabrication (invariant #8). Encoding: UTF-8, falling back to
`latin-1` with a warning rather than raising, because a legacy corpus will
contain both.

READERS: dict[str, Callable] = {".docx": read_docx, ".html": read_html,

### 3.5 `src/lexml_nonstat/cli.py` — the unified CLI

```
lexml-nonstat <command> [options] [paths...]
python3 -m lexml_nonstat <command> [options] [paths...]

commands
  parse             render a document to LexML XML
  dump-styled       what ingestion saw            (Cycle 1's view)
  dump-tree         the inferred hierarchy        (Cycle 4's view)
  segment           citable segments, CSV/JSONL   (Cycle 7's view)
  validate          validate XML against the schemas
  list-profiles     the registered profiles
  decisions-report  §7.4's rule-vs-referee summary
  capabilities      what the schemas present permit (A-R.9)
```

Global options, accepted by every command that takes documents:

| Flag | Values | Default | Meaning |
|---|---|---|---|
| `--profile` | a registered name | auto | force a profile |
| `--emitter` | `auto` \| `generico` \| `generico-aninhado` \| `norma` | `auto` | rendering (R-10) |
| `--schema` | `SCHEMA_SELECTORS` | `both` | which schema(s) validate |
| `--generation` | `GENERATIONS` | `shipped` | which schema generation to probe |
| `--referee` | `REFEREE_MODES` | `none` | adjudicator (D-7) |
| `--referee-model`, `--referee-cache` | | | as `routing/__main__` |
| `--strict` | flag | off | any warning or invalid output ⇒ exit 1 |
| `--format` | per command | per command | `text` \| `json` (+ `csv`/`jsonl` for `segment`) |
| `-o/--out` | directory | — | write bundle documents to files (R-9) |
| `-q/--quiet` | flag | off | suppress per-document headers |

**Exit codes**, one meaning each:

| Code | Meaning |
|---|---|
| 0 | every document handled; no warning under `--strict` |
| 1 | a document failed — unreadable source, invalid output, or (under `--strict`) any warning |
| 2 | the invocation itself is wrong — unknown profile, unknown emitter, unsupported format, unavailable emitter requested |

`--emitter=generico-aninhado` on a checkout without the capability exits **2**
with `probe_capabilities(PROPOSED).diagnostic` on stderr and no traceback —
A-R.9's requirement, verbatim.

`main(argv: list[str] | None = None) -> int` is the whole public surface, so
every test drives it in-process and one subprocess test proves the module and
script forms reach it.

cleanest structured document and Cycle 5b's A-5b.4 already uses it as the
reference for id shapes.

## 7. Risks

| Risk | Mitigation |
|---|---|
| **`Warning` shadows the builtin** and someone later writes `except Warning:` meaning the builtin | The module is `lexml_nonstat.warnings`, never `import *`-ed; grep confirms no builtin `Warning` use in the codebase; a test asserts `lexml_nonstat.warnings.Warning` is not a subclass of the builtin |
| **`--emitter=auto` makes CLI output depend on routing**, so a routing change silently changes CLI output | `test_cli_output_matches_the_library` pins the CLI to the library's answer rather than to a literal, and `test_auto_matches_the_route` names the mapping. §4.4's route goldens already pin routing itself |
| **HTML/TXT readers have no ground truth** — nothing says my mapping is right | Discharged the A-1.3 / A-4.6 way: a synthetic fixture asserting the *pipeline* reaches the same tree from two formats is a stronger claim than a golden of the reader's own output, and it is the plan's actual bullet |
| **Degenerate fixtures built at test time make the suite slower** | Ten small documents built once per session via a session-scoped fixture; measured against the 21s baseline and reported |
| **A CLI is easy to test shallowly** — asserting exit 0 proves little | Every subcommand test asserts on *content*: the byte-identity tests against the library, the CSV header against `CSV_COLUMNS`, the block count against `read_docx` |
| **`--strict` semantics could swallow output** | Pinned: `--strict` changes only the exit code, never stdout. Asserted directly |
| **The 60-invocation corpus sweep could dominate runtime** | Models are built once per sample in a session-scoped fixture and the CLI is driven in-process; only one test uses a subprocess |
