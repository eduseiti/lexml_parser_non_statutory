## 2. Measurements taken before writing this spec

The plan requires these to be *measured*, never argued (§2.8's method, A-L.2,

### 2.1 `Remissao` legality — A-L.2's question, and the `<a>` nesting question

`scratchpad/probe_schema.py`, 8 fragments × 2 schemas × 2 generations:

| Fragment | `rigido` | `flexivel` | Both generations |
|---|---|---|---|
| `<p>ver <Remissao xlink:href="urn:lex:…">…</Remissao></p>` | valid | valid | agree |
| `<Remissao>` with **no** `xlink:href` | **invalid** | **invalid** | agree |
| `Remissao` **inside** `<a>` | valid | valid | agree |
| `<a>` **inside** `Remissao` | valid | valid | agree |
| `Remissao` in `<td>` | valid | valid | agree |
| `Remissao` in `<li>` | valid | valid | agree |
| `Remissao` inside `Remissao` | valid | valid | agree |
| `Remissao` inside an `Agrupamento`'s `<p>` | valid | valid | agree |

So: `xlink:href` is **required**, as A-L.2 read off the XSD — and the A-L.2
`<a>`-nesting question is **answered by measurement**: legal in *both*
directions. §2.8's "the two schemas do not differ on the generico surface"
holds on this surface too. These become matrix rows (§6.1, T-M1…T-M4).

### 2.2 Context-URN acceptance — the load-bearing risk (§6.1 of the record)

`--contexto` is a `parseURNLexML` input. Isolating one component at a time,
with the same citation sentence and the same binary:

| Context URN | Refs found |
|---|---|
| `urn:lex:br:federal:lei:2000-01-01;1` (the reference parser's default) | **yes** |
| `urn:lex:br:federal:parecer:2018-06-07;277` — non-statutory **type** | **yes** |
| `urn:lex:br:federal:ato.declaratorio:2018-06-07;277` | **yes** |
| `urn:lex:br:federal:portaria:2018-06-07;277` | **yes** |
| `urn:lex:br:federal:lei:0000-00-00;277` — A-2.3's **sentinel** | **yes** |
| `urn:lex:br:federal:lei:0000;277` | **yes** |
| `urn:lex:br:ministerio.fazenda:lei:2018-06-07;277` — **authority** | **no** |
| `urn:lex:br:ministerio.fazenda;secretaria.receita.federal:lei:…` | **no** |

**The authority is the sole breaking component.** The two things A-L.8
predicted would be the problem — the `;`-joined authorities and the `0000`
sentinels — are both harmless; the plain single-token non-federal authority is
what silently disables the whole grammar. And every one of the 15 samples
carries one (`ministerio.fazenda`, `advocacia.geral.uniao`,
`superior.tribunal.justica`, `procuradoria.geral.fazenda.nacional`).

The failure is **silent**: the linker echoes the fragment back unchanged, so a
rejected context is indistinguishable from a paragraph that cites nothing.
That is what makes the fallback a correctness requirement rather than a
convenience. Recorded as amendment **A-L.9**.

Non-blocking decisions taken without asking:

- **N-1.** Test files: `tests/unit/test_refs_protocol.py`,
  `test_refs_linkertool.py`, `test_refs_cache.py`, `test_refs_probe.py`,
  `test_render_remissao.py`, and `tests/regression/test_linked_invariants.py`.
  Existing files gain cases rather than being split.
- **N-2.** Fixture directory `tests/linker_fixtures/`, one JSON file per key,
  exactly `referee_fixtures/`'s shape.
- **N-3.** `Reference` is `@dataclass(frozen=True, order=True)` so overlapping

- **N-5.** The linker is asked about **`Para` text only** — not table cells,
  not list items — in this cycle. Rationale in §9 (Risks); the readers are
  still made read-through everywhere, so widening later moves no golden.

## 4. Expanded goals — exact deliverables

### 4.1 `src/lexml_nonstat/refs/` — new subpackage, mirroring `referee/`

**`refs/protocol.py`**

```python
DEFAULT_CONTEXT_URN = "urn:lex:br:federal:lei:2000-01-01;1"   # A-L.8, A-L.9

@dataclass(frozen=True, order=True)
class Reference:
    start: int          # character offset into Para.text, inclusive
    end: int            # exclusive
    urn: str
    text: str           # the source text of the span, verbatim

    @property
    def is_empty(self) -> bool
    def to_dict(self) -> dict[str, Any]
    @classmethod
    def from_dict(cls, data) -> "Reference"

@runtime_checkable
class Linker(Protocol):
    name: str
    def find_refs(self, text: str, context_urn: str = DEFAULT_CONTEXT_URN
                  ) -> tuple[Reference, ...]: ...
```

`find_refs` **never raises** — every failure (missing binary, timeout, dead
co-process, malformed output) returns `()`. This is the referee's abstention
rule transposed: a linker outage degrades quality, never availability.

**`refs/null.py`** — `NullLinker`, `name = "none"`, `enabled = False`,
`find_refs` → `()`. **The default everywhere** (A-L.1).

**`refs/linkertool.py`** — `LinkertoolLinker(binary=None, *, cache=None, timeout=30.0)`.
Long-lived co-process, `--hxml --xml --contexto=INLINE`, `###LEXML-END###`
framing, `span/@xlink:href` harvested into character spans over the input text.
Lazily spawned on the first uncached query (Q-4); `close()` + `atexit`.
`spawns` counter, for T-F2.

**`refs/cache.py`** — `LinkerCache(directory, *, read_only=False)` with
`hits`/`misses`, and `cache_key(context_urn, text) -> str` (sha256, 32 hex).
Same shape as `RefereeCache`; stores a *list* of references.

**`refs/probe.py`** — `LinkerCapabilities(available, path, version, diagnostic)`
and `probe_linker(binary=None) -> LinkerCapabilities`. **Never raises.**
Searches `/usr/local/bin/linkertool` **first**, then `PATH` (A-L.5).

**`refs/__init__.py`** — `LINKER_MODES = ("none", "auto", "fixtures")`,
`build_linker(mode="none", **kwargs)`, and the re-exports.

### 4.2 `<Remissao>` emission — `render/common.py`

```python
def apply_references(inlines, references) -> tuple[Inline | _Ref, ...]   # internal
def render_inlines(parent, inlines, references: Sequence[Reference] = ()) -> None
def render_para(para: Para, *, references: Sequence[Reference] = ()) -> ...
def render_node(node, *, table_id, linker=None, context_urn=DEFAULT_CONTEXT_URN)
```

Nesting order becomes **`a` → `Remissao` → `b` → `i` → `sup` → `sub`** (Q-2).
Overlapping references: the **first** by `(start, -end)` wins and later
overlaps are dropped — deterministic, and it cannot produce interleaved markup.
A reference is dropped, never truncated, if it does not lie wholly within the
paragraph's text.

Existing callers pass no `references` and get **byte-identical** output; that
is what keeps the 125 goldens still (T-G1).

### 4.3 Read-through — A-L.4

Measured during reconnaissance: `leaf_texts` already calls
`_own_text(node, frozenset())` for `<p>`/`<td>`, which descends into **every**
child, so a nested `Remissao` is already read. This cycle therefore **asserts**
that rather than changing it, and changes only what measurement shows is
broken:

- `render/common.py:leaf_texts` — asserted read-through (T-C1).
- `segments/api.py`'s three readers — asserted read-through (T-C2).
- `segments/stylesheets/*.xsl` ×3 — `string-join(.//text())`-style selects
  must not stop at `Remissao`; asserted by the XSLT-vs-Python row comparison
  Cycle 7 built (T-C3).

Anything that turns out **not** to read through is a defect fixed in this
cycle and logged.

### 4.4 Fixtures and goldens — A-L.6

- `tests/linker_fixtures/` — one JSON per `(context_urn, text)` key.
- `scripts/record_linker_fixtures.py` — explicit, never automatic; `--check`

- `scripts/regen_goldens.py` `KINDS` gains `generico-linked` →

### 4.5 CLI — A-L.7

`--linker=none|auto|fixtures|<path>` (default `none`) and `--linker-cache=DIR`
on `parse`. `capabilities` reports the linker beside the schema generations.
`build_model` is **not** touched: resolution is at render time (A-L.3), so the
linker is threaded into `_render`.

**A-C.1's lesson is discharged by T-X1**, which asserts that `--linker=none`
and `--linker=fixtures` produce *different* bytes on a document that cites a
statute — not merely that the flag is accepted.

## 8. Amendments this cycle proposes

- **A-L.9** (new) — *The context URN is always `urn:lex:br:federal:lei:2000-01-01;1`.*
  A-L.8 anticipated that the `;`-joined authorities and the `0000` sentinels
  might be rejected and named the fallback as documented. Measurement (§2.2)
  shows the sentinels and the non-statutory **types** are all accepted, and
  that the **authority alone** is what silently disables the grammar — for all
  15 samples. So the fallback is not a fallback: it is the only context this
  corpus can use, and passing our own URN would resolve nothing while looking
  like it worked. `find_refs` keeps `context_urn` as a parameter, so a future
  linker that learns our authorities needs no new API.

## 9. Risks

1. **A silent-zero linker.** §2.2's failure mode returns the input unchanged.
   Mitigated by T-L4, which pins the rejection, and by T-X1, which asserts the
   flag *moves bytes* on a real document — the A-C.1 shape of failure.
2. **Conservation.** A-6.4's precedent: valid on both schemas and 29 words
   short. Mitigated by T-C1's **character** multiset over all 15 samples, and
   by T-C2/T-C3 covering the readers and both stylesheets — no schema can see
   this class of damage.
3. **Encoding.** `linkertool` dies on non-ASCII under a non-UTF-8 locale
   (measured, N-4). The corpus is Portuguese; every paragraph is non-ASCII.
   Cycle 8 lost four defects to exactly this, one of which conservation
   *structurally could not detect* because both sides carried the same
   mojibake. Mitigated by the explicit locale/encoding and by T-L2's exact
   `text[start:end] == ref.text` assertion, which compares against the input
   rather than against another copy of the output.
4. **Offset drift.** The linker returns decorated XML; offsets must be
   recovered by walking it. XML-escaping (`&amp;`, `&lt;`) makes the naive
   string-index approach wrong. Mitigated by T-L2 and by building spans from
   the parsed tree's text nodes rather than from the raw string.
5. **Run splitting moves leaf boundaries.** A split `<b>` changes
   `leaf_texts`' tuple *shape* without changing its characters — which is
   precisely why T-C1 compares characters and not the tuple.
6. **Scope creep into table cells and list items** (N-5). Deliberately not
   done; the readers are made read-through anyway, so widening later moves no
   golden and needs no re-measurement.
