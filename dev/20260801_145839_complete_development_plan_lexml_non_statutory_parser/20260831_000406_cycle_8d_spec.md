```python
PROSE_HEADER_MAX_WORDS = 7
PROSE_HEADER_MAX_CHARS = 60

#: …and at least this fraction of its letters are uppercase.
PROSE_HEADER_MIN_UPPER = 0.85

def is_prose_form_header(para: StyledPara, *, quoted: bool) -> bool:
    """Is ``para`` typographically distinctive but formally unlabelled?"""
```

`Candidate` gains `prose_form: bool = False`. `is_candidate` gains **one** new
clause, and it is deliberately *not* an admission:

```python
@property
def is_candidate(self) -> bool:
    if self.quoted:
        return False
    if self.style is not None:
        return True
    if self.prose_form:
        return True                      # only ever set post-confirmation
    return self.label is not None and not self.label.is_dispositivo
```

`prose_form` is set **only** by the confirmation step in `tree.py` (G-3), never
by `collect_candidates`. A candidate the referee did not confirm keeps
`prose_form=False` and is invisible to `unify_levels`, exactly as today.

`collect_candidates` gains a keyword-only `prose_form_indices: frozenset[int] =
frozenset()` and sets the flag from it.

### G-4 — the depth rule (A-H.4)

In `unify_levels`, a confirmed prose-form candidate:

1. **clears the stack** and opens at **depth 1** with key `("prose", index)` — a
   key unique per header, so two prose headers are never mistaken for a series;
2. sets `previous_depth = 1`;
3. carries `heading = candidate.text`, `label = None`,
   `kind = section_kind(None, 1)` → `"secao"`, and score
   `W_PROSE_HEADER_CONFIRMED`.

The parenting of the numeric series is then **automatic**, and this is the part
worth stating precisely because it is why no change to the numeric branch is
needed: a depth-1 numeric currently does `stack = []; depth = 1`. With a prose
header open, that would put `2.` beside `RELATÓRIO` rather than under it. So the
numeric branch gains exactly one guard — *if a prose header is open on the
stack, a top-level numeric anchors beneath it* (`depth = prose.depth + 1`,
stack popped to the prose header rather than emptied).

`W_PROSE_HEADER_CONFIRMED = 0.8` in `evidence.py`, matching `W_UNIT_SERIES` —
a referee-confirmed header is strong evidence but not style-strong, and 0.8 is
comfortably above `CONFIDENCE_THRESHOLD` so a document made *only* of prose
headers is still declared structured.

### G-5 — heading text moves, it does not duplicate (A-H.5)

`_assemble` already drops a header paragraph from the body and puts its text on
