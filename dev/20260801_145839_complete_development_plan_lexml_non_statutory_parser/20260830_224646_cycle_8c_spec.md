### 2.2 Corrections to the record

Three, none of which change the amendment's shape.

**C-1 — the record's line reference is stale.** §2.2 cites
`hierarchy/tree.py:412` as the `analyse_quotation` call site. It is
`build_tree`, at **`tree.py:430`**. Cosmetic; noted so the next reader is not
sent to the wrong line.

**C-2 — `parecer_93`'s two "norm heads" are not multi-norm boundaries, and this
matters.** The record's §3 census counts blocks 268 and 321 in `parecer_93` as
the same `{norm} - "{Art. N}` shape found at `par_cosit_26`'s 63/69/76. Dumped,
they are not:

```
268  Q  'Lei no 12.618. de 2012)'          ← a trailing citation fragment,
                                              the tail of a quotation, no article follows
321  Q  '"Súmula 207'                      ← a quotation opener, not a norm head
```

Neither is `{norm designation} + {article marker}`. The census regex
(*"opens with a norm noun, inside a quoted run"*) is looser than the shape
A-Q.2 actually proposes to key on. **Consequence:** the corpus's true A-Q.2
surface is **4 paragraphs in 1 sample** — `par_cosit_26` blocks 45, 63, 69, 76
— not 6 in 2. This *strengthens* the amendment's own §4 argument rather than
weakening it: the generator must be written from the shape, and blocks 268/321
are exactly the false positives it must **not** fire on. They become negative
assertions in the test plan (T-8c.4).

**C-3 — the two emitters order body and children oppositely, and A-Q.4 walks
straight into it.** Measured:

- `render/generico.py:_section_elements` emits the section's **body first**,
  then flattens `children` as *siblings* after it.
- `render/generico_aninhado.py:_section_element` emits **children first**
  (§5.4 Constraint 1, A-5b.1), then the section's own prose.

So a `Section` carrying both body and children serialises in **opposite text
order** on the two emitters. This is already known, already documented, and
already tested: `test_text_order_diverges_exactly_where_constraint_1_says`
asserts divergence occurs on **exactly** those documents with such a section.

Two consequences, both binding on this cycle:

1. A-Q.4 must **move** the run's paragraphs out of the parent's `body` into the
   child `Section`, never copy them, and never leave a partial run behind. A
   copy is a conservation failure (invariant #2, duplication half); a partial
   run is what A-Q.5's gate exists to refuse.
2. `par_cosit_26` will flip from "no reordering" to "reordering" in that test.
   That is a **predicted, asserted** consequence, not a regression — the test
   computes its expectation from the tree, so it stays green by construction if
   and only if the tree and the emitters agree. This is A-Q.6's "third drift"
   check, and it already has a home.

## 3. Expanded goals

### A-Q.1 — `QuoteRun`, and the guard returns spans

`hierarchy/quotation.py` gains:

```python
@dataclass(frozen=True)
class QuoteRun:
    indices: tuple[int, ...]          # the paragraphs, document order
    head: int | None = None           # the paragraph introducing the norm
    norm: str | None = None           # "Lei nº 7.713, de 1988" — as written
    antecedent: int | None = None     # the announcing paragraph, outside the run
    evidence: Evidence = Evidence()   # why this is a boundary
    def to_dict(...); from_dict(...)  # golden-serialisable, house style
```

and `QuotationAnalysis` gains `runs: tuple[QuoteRun, ...] = ()`.

**`quoted` is unchanged in meaning and in value.** Every existing consumer —
`tree.py`'s `Para.kind`, `viability.py`'s census, all goldens — reads the same
frozenset it read before. **The test of A-Q.1 is that all goldens stay
byte-identical.**

`runs` are the maximal contiguous spans of `quoted` in document order, split
at confirmed boundaries. With no boundaries confirmed, one run per maximal
contiguous span — which is `par_cosit_26`'s 4 (as `analyse_quotation` already
sees them) and `parecer_93`'s 58.

### A-Q.2 — deliberately over-generous candidate generation

A **quotation head** is a paragraph that opens with a norm designation followed
by an article marker, within a small window:

```
{norm word} … {number}  …  ["-,] … {Art.|Artigo} {N}
```

Written from the shape, not from the corpus: reuse `_NORM_WORDS` and its
folded-accent matching, require an article marker to follow the norm within the
paragraph's opening, and require the paragraph to sit inside or adjacent to a
quoted run.

Recall over precision, as the record directs — but C-2's negatives are hard
constraints: `Lei no 12.618. de 2012)` (no article marker follows) and
`"Súmula 207` (no article marker) must **not** be proposed.

**A-Q.2 also fixes §3's defect.** A recognised quotation head is quoted
material, so `par_cosit_26` block 45 gains `class="quote"`. This is
golden-changing: **one sample, one paragraph.** Rejected candidates are
recorded (the A-4.2 / `DocSignals.rejected` precedent).

### A-Q.3 — a fourth referee question, confirm-only

`referee/protocol.py`:

```python
BOUNDARY_VERDICTS: tuple[str, ...] = ("boundary", "continuation")

class Referee(Protocol):
    ...
    def quotation_boundary(self, excerpt: str, ctx: str) -> Verdict: ...
```

- `prompts._TEMPLATES["quotation_boundary"]` + `VOCABULARIES` entry.
- `adjudicate._METHODS["quotation_boundary"] = "quotation_boundary"`.
- Implemented on `NullReferee` (inert), `CachedAPIReferee`, `LocalReferee`.
- `ctx` is the **announcing paragraph** — the antecedent that names the norms —
  not merely the preceding one. Same `MAX_CONTEXT_CHARS` / `MAX_EXCERPT_CHARS`
  caps, so every §7.3 privacy guarantee is inherited unchanged.
- Adjudication goes through the existing `adjudicate()` **unmodified**: same
  `FLAG_THRESHOLD`, `RULE_HIGH_CONFIDENCE`, `REFEREE_MIN_CONFIDENCE`,
  `DecisionRecord`, cache.

**The referee may only veto.** A candidate the generator did not propose can
never become a boundary, whatever the referee answers. Asserted as an attack in
the A-4b.6 style.

### A-Q.4 — confirmed runs become child `Section`s

In `tree.py`, a section whose body contains **two or more** confirmed runs
splits: one child `Section` per run.

- `kind = "citacao"` — a new `SECTION_KINDS` member
- `heading = run.norm` — as written; becomes `NomeAgrupador`
- `body` = the run's paragraphs, **moved** out of the parent (never copied),
  `Para.kind` unchanged
- `level` = parent level + 1
- `evidence` records the cue and whether a referee confirmed it

Single-run sections stay flat (the record's A-Q.5 second paragraph): wrapping a
lone quotation adds no distinction and would churn every sample in §4's table.

### A-Q.5 — the gate: nest only when the whole run is accounted for

A section's quoted material splits into children **only if** every paragraph of
every run lands in exactly one child, and the parent's remaining body plus the
children's bodies reproduce the parent's original body exactly, in order, with
no loss and no duplication. Otherwise the section stays flat. Conservation is a
**precondition** of nesting, not an afterthought — the A-6.3 lesson.

### A-Q.6 — cross-emitter equivalence

`par_cosit_26`'s goldens change across the affected kinds; the segmentation
output gains rows for the new sections. **Every other sample byte-identical.**
Verified on `Segment.path`, not `Segment.urn` (A-7.2).

### A-Q.7 — `own_articulation`'s `ctx` widened (user answer 3; **major**)

`routing/viability.py:_adjudicate_articles` currently passes the immediately
preceding non-empty paragraph as `ctx`. It will instead pass the **nearest
preceding citation antecedent** — the nearest earlier paragraph for which
`names_external_norm` is true — falling back to the immediately preceding
paragraph when there is none.

This is what §2.3 of the record diagnosed: for `par_cosit_26` p#47 the owner
(`Lei nº 7.713, de 1988 - "Art. 1º-…`, block 45) sat two paragraphs back and
was structurally outside the window.

Consequences, all of them accepted by the user in advance:

- every `own_articulation` cache key moves;
- the four committed fixtures are **re-keyed by replay, never typed** (A-C.4's
  method), verdicts/confidences/rationales/`origin` untouched;
- rule verdicts and `--referee=none` behaviour are unchanged, so **no golden
  changes** from A-Q.7 alone.
