### 2.1 The indentation finding (load-bearing — plan correction)

The plan's Cycle 1 test reads: *"the 21 quoted articles in `parecer_93` show `ind≈2880–2930` vs modal 0"*.

**Confirmed:** exactly **21** `Art.`-initial paragraphs, at `w:ind/@w:left` ∈ {2880, 2908 (×18), 2930}. The count and the band both match the plan precisely.

**Corrected:** the modal indent is **not 0**. It is **2908 — the quote band itself**.

- The `Normal` style itself declares `<w:ind w:left="2909" w:right="22" w:firstLine="4"/>`.
- The 2880–2930 band holds **137 non-empty paragraphs**, not 21: the whole quoted excerpt (incisos, alíneas, continuation paragraphs) shares the indent of the `Art.` line heading it, spread across blocks 10–416. Only **20** of the 137 begin with `Art.`.
- Only **37** paragraphs sit in the small band (7–60): front matter and unquoted commentary.
- 226 paragraphs have no direct `w:ind` at all — but **219 of those are empty or section artifacts**; only 1 is a non-empty real paragraph (a `Heading 1`).

> **Corrected during implementation.** This section first read "body paragraphs carry direct `w:ind` with small values: 7, 24, 29, 50, 58, 60", which describes only those 37 paragraphs and implied the modal was among them. The test derived from it (`test_parecer_93_body_indent_is_small`, §6) asserted a falsehood and failed on first run. The real discriminator is **quote band vs small band** — disjoint by an order of magnitude, so any threshold in 100–2800 separates them — *not* quote band vs modal. Cycle 4 must not threshold against the modal indent: that would classify most of the document as unquoted body. Recorded as plan Amendment A-1.1 point 1.

Consequence: reading **effective** (style-inherited) indent collapses the discriminator — the inherited modal 2909 sits one twip from the quote band 2908. Reading **direct** `w:ind` separates them cleanly but reports `None` for 226 paragraphs. Neither alone is sufficient, which is why `StyledDoc` records both (§3, Q1).

### 2.2 Constructs the plan's bullet list omits, present in real samples

- **Struck runs** — 18 in `sumula_stj_125`. The Scala reference (`DOCXReader.stripStruckRuns`) drops them *before* soft-break splitting, and its comment explains why: a struck run can contain `<w:br/>`-separated segments, so splitting first lets struck text leak out of its `<w:rPr>`.
- **Hyperlinks** — 11 in CARNE_LEAO. Plan §3.1's `Inline` already declares `href: str | None`, so the target has a home.
- **Soft breaks** — `<w:br/>` in 3 samples (10 total). The reference splits paragraphs at them.

### 2.3 NFC

All 15 samples are **already NFC**: `text == unicodedata.normalize("NFC", text)` holds for every one. A test asserting "NFC unifies composed/decomposed accents" run against the samples would pass with the normaliser deleted. Note also that the Scala `breakText` does *not* normalise — it only collapses whitespace (`[ \s\n\r]` → space, then `\s\s+` → space).

### 2.4 Block order

Tables are interleaved mid-document, not appended: `REsp_1306393` has its table at block index 4 of 21, `sumula_stj_125` at 10 of 397, `par_cosit_26` at **11** of 104. `python-docx`'s `.paragraphs` and `.tables` accessors flatten this away, so ingestion must walk `body` children directly to preserve order.

> **Corrected during implementation.** The `par_cosit_26` figure was first recorded as "9 of 101", counted on *source paragraphs*. That sample has 4 soft breaks, all before the table, and `index` is assigned **after** splitting — so the table lands at block 11 of 104. The pre-split number was never the one the model reports.

## 3. Reconciliation outcomes

Four blocking questions were put to the user. All four answered.

### Q1 — Indent model → **both direct and effective**

Given the §2.1 finding, `StyledPara` carries `indent_direct` (the paragraph's own `w:ind/@w:left`, `None` when absent) **and** `indent_effective` (resolved through `pStyle` → `basedOn` chain → `docDefaults`). Cycle 4's quotation guard chooses whichever discriminates. No information is lost, and the 2909 style trap is explicit in the data rather than buried.

### Q2 — Edge cases → **mirror the reference parser, plus capture `href`**

Drop struck runs (toggle-aware: `w:val` ∈ {`false`, `0`, `off`} disables the strike), split paragraphs at `<w:br/>`, and capture hyperlink targets into `Inline.href`. Ordering follows the reference parser: **strip struck runs first, then split at soft breaks**, for the reason quoted in §2.2.

### Q3 — NFC → **synthetic fixture + samples-are-NFC guard**

Keep NFC normalisation. Test it with synthetic decomposed input so the test fails if the normaliser is removed, *plus* a standing test asserting all 15 samples are NFC-unchanged — documenting today's corpus state and acting as a tripwire for the first non-NFC document.

### Q4 — Goldens → **`scripts/regen_goldens.py` + conservation test**

A committed script regenerates `tests/golden/styled/<sample>.json`; tests compare byte-for-byte. Separately, a conservation test gives "losslessly" an objective meaning independent of golden content (§6).

### Non-blocking decisions taken without asking

| Decision | Rationale |
|---|---|
| `StyledDoc` field shape (§4) | The plan never specifies it. Designed to serve Cycles 3/4 (segmentation, hierarchy) without forcing a later rewrite. |
| Module split: `styled.py` (model) + `docx_reader.py` (reader) | Plan §3 layout lists both files. `styled.py` holds pure dataclasses so `html_reader`/`txt_reader` (Cycle 8) can reuse them without importing `python-docx`. |
| `Inline.strike` **not** added | Per Q2 struck runs are dropped, so no flag is needed; keeps `Inline` aligned with plan §3.1. |
| JSON goldens: 2-space indent, `ensure_ascii=False`, `sort_keys=False` | Readable diffs; field order is the dataclass order, which is semantic. |
| `--dump-styled` as `python -m lexml_nonstat.ingest` | Mirrors Cycle 0's `python -m lexml_nonstat.validate`. The unified `cli.py` with a `dump-styled` subcommand is Cycle 8's deliverable (plan §8 line 787); building it now would pre-empt that cycle. |
| Empty paragraphs retained | `StyledPara` with empty `inlines` is kept, flagged by `is_empty`. Cycle 3's front/back-matter segmentation may use blank lines as separators; dropping them now is irreversible. |

## 4. Expanded goals — public API as specified

### `src/lexml_nonstat/ingest/styled.py`

```python
@dataclass(frozen=True)
class Inline:
    text: str
    bold: bool = False
    italic: bool = False
    sup: bool = False
    sub: bool = False
    href: str | None = None

@dataclass(frozen=True)
class StyledPara:
    inlines: tuple[Inline, ...]
    style: str | None                 # resolved w:pStyle name
    style_id: str | None              # raw w:styleId
    outline_level: int | None         # from style w:outlineLvl; Heading 1 -> 0
    num_id: str | None                # w:numPr/w:numId
    ilvl: int | None                  # w:numPr/w:ilvl
    indent_direct: int | None         # w:ind/@w:left on the paragraph itself
    indent_effective: int             # resolved via pStyle/basedOn/docDefaults
    first_line: int | None            # w:ind/@w:firstLine
    hanging: int | None               # w:ind/@w:hanging
    alignment: str | None             # w:jc/@w:val
    index: int                        # 0-based position among body blocks

    @property
    def text(self) -> str: ...        # concatenated inline text
    @property
    def is_empty(self) -> bool: ...   # text.strip() == ""

@dataclass(frozen=True)
class StyledCell:
    paras: tuple[StyledPara, ...]

@dataclass(frozen=True)
class StyledRow:
    cells: tuple[StyledCell, ...]

@dataclass(frozen=True)
class StyledTable:
    rows: tuple[StyledRow, ...]
    index: int                        # 0-based position among body blocks

@dataclass(frozen=True)
class StyledDoc:
    blocks: tuple[StyledPara | StyledTable, ...]   # source order preserved
    source: str | None = None                      # sample filename, not a path

    @property
    def paragraphs(self) -> tuple[StyledPara, ...]: ...
    @property
    def tables(self) -> tuple[StyledTable, ...]: ...
    @property
    def text(self) -> str: ...
    def to_dict(self) -> dict: ...
    def to_json(self, *, indent: int = 2) -> str: ...
    @classmethod
    def from_dict(cls, data: dict) -> "StyledDoc": ...
```

`source` holds the bare filename, never an absolute path — goldens must not encode this machine's directory layout.

### `src/lexml_nonstat/ingest/docx_reader.py`

```python
def read_docx(path: str | Path, *, drop_strikethrough: bool = True) -> StyledDoc
def normalize_text(text: str) -> str      # NFC + whitespace collapse (breakText rules)
class StyleResolver:                       # pStyle/basedOn/docDefaults resolution
    def name(self, style_id: str | None) -> str | None
    def indent(self, style_id: str | None) -> int | None
    def outline_level(self, style_id: str | None) -> int | None
```

`normalize_text` mirrors `DOCXReader.breakText`'s whitespace rules exactly — `[ \s\n\r]` → single space, then `\s\s+` → single space — with NFC applied first (the reference's one documented deviation, per Q3). Leading/trailing spaces are preserved at the inline level (the reference emits `Space` segments for them) but `StyledPara.text` is what tests assert on.

Cycle-safety: `basedOn` chains are followed with a `seen` set, so a cyclic style graph terminates instead of hanging.

### `src/lexml_nonstat/ingest/__main__.py`

```
python -m lexml_nonstat.ingest samples/parecer_93_2018_decor_cgu_agu.docx
python -m lexml_nonstat.ingest --format=text samples/*.docx
```

`--format=json` (default) emits `StyledDoc.to_json()`; `--format=text` emits one readable line per block for eyeballing. Exit 0 on success, 1 on unreadable input.

### `scripts/regen_goldens.py`

```
python3 scripts/regen_goldens.py            # regenerate all 15
python3 scripts/regen_goldens.py parecer_93_2018_decor_cgu_agu
```

Writes `tests/golden/styled/<stem>.json`. Prints a per-sample diff summary so a regeneration that changes goldens is visible in the terminal, not just in `git diff`.

## 8. Risks

| Risk | Mitigation |
|---|---|
| `python-docx` version drift changes golden bytes | Goldens derive from our own dataclasses, not the library's repr. Pinned floor in `pyproject.toml`. |
| Soft-break splitting changes paragraph indices, breaking Cycle 3/4 assumptions | `index` is assigned post-split and documented as the authoritative position; conservation test proves no text is lost. |
| Struck-run dropping hides content a later cycle needs | `drop_strikethrough=False` retains it; both paths tested. |
| Effective-indent resolution wrong for `docDefaults`-only documents | `test_style_indent_inherited` plus explicit `docDefaults` fallback; no sample relies on it today, so it is exercised synthetically. |
| Golden churn from ordering instability | `test_determinism` ×15; dict field order is dataclass order, not `set` iteration. |
| Conservation test too weak to catch real loss | It compares *per-paragraph* normalised text with exact-once multiset semantics, not a substring check over the whole document. |
