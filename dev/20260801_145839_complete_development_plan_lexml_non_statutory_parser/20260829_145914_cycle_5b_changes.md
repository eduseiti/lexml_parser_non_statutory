## C-1 — `test_httpx_is_not_imported` rewritten (**escalated and approved**)

| Field | Content |
|---|---|
| **What changed** | `tests/unit/test_referee_api.py::test_httpx_is_not_imported`, plus the module docstring's claim that "`httpx` is not installed in this environment" |
| **Before** | `assert "httpx" not in sys.modules` before and after exercising the referee — a claim about the **whole interpreter** |
| **After** | A probe run in a **clean isolated subprocess** (`python3 -I -c …`, no pytest plugins) that imports `lexml_nonstat.referee`, asks the referee a question, and prints whether `httpx` entered `sys.modules`. The test asserts `False`. The in-process exercise is kept afterwards |
| **Why** | The baseline suite was **red by this one test**. The `langsmith` pytest plugin — auto-loaded from a `pytest11` entry point in this conda environment — does `import httpx` at plugin-load time, before any test collects (traced to `site-packages/langsmith/utils.py:38`). The package under test was entirely clean: a `builtins.__import__` trace over `import lexml_nonstat.referee.api` showed no `httpx`, and `PYTEST_DISABLE_PLUGIN_AUTOLOAD=1` made the test pass. The invariant is about **our** import graph; the assertion was about the interpreter's |
| **Blast radius** | This test only. No `src/` change. Nothing else asserts on `sys.modules` |
| **Plan impact** | None — §7.3's "the extra stays optional" is unchanged and now better tested |
| **Severity** | **Major** (an existing test changed) — presented to the user with three options (harden / leave failing / pin the plugin off); the user chose **harden** |

**A wrong first attempt, recorded because it matters.** The obvious repair was
to snapshot presence before and after and assert it unchanged. That is
**strictly weaker**, and a mutation proved it: with a module-level
`import httpx` injected into `src/lexml_nonstat/referee/api.py`, the snapshot
form **survived** — once a third party has already imported `httpx`, our own
module-level import changes nothing about the snapshot, and the guard silently
stops guarding. The subprocess form **kills** that mutation. Both mutations were
run against a copy-restore of `src/`, verified byte-identical afterwards.

Net effect: the guard is *stronger* than the one it replaces — it is immune to
third-party imports **and** it catches a module-level import in our own code,
which the original could only do by accident of environment.

## Considered and rejected

**R-1 — asserting nested output is invalid on the shipped schemas for all 16
documents.** Written that way first; it failed on six. Six of the sixteen
documents contain **no `AgrupamentoHierarquico` at all** — `REsp_1306393`,
`ad_pgfn_3`, `ad_srf_22`, `adn_cosit_19`, `sumula_carf_42`, and
`port_mf_277`'s *primary* (all 65 of its sections live in the annex). They are
nothing but front and back matter, which both emitters render identically
through the shared `front_region`/`back_region` (A-5.1), so their nested output
is byte-identical to their flat output and is *correctly* valid on `lexml/`.
Asserting invalidity for all sixteen would have pinned a defect rather than a
property. The test became `…_iff_nested`, and a companion
`test_exactly_the_expected_documents_nest` pins the partition itself so a change
in hierarchy inference cannot silently move a document between the two groups.

**R-2 — making `render_generico_aninhado()` refuse when the schemas are flat.**
§5.2 says the emitter "refuses with the probe's diagnostic when the vendored
schemas are flat", but `lexml/` — the shipped generation, the default
everywhere — **is** flat, so a literal reading refuses on every default
checkout, including inside the emitter's own tests. Escalated to the user, who
chose: the renderer is pure and always renders; *emitter selection* (the CLI,
Cycle 8) and *validation* are what consult the probe. Recorded as spec R-2 and
as a proposed clarification to §5.2.

**R-3 — emitting `<Bloco nome="ordem">` only on unlabelled sections**, which is
the cycle bullet's literal wording. Escalated; the user chose uniform emission
on every child. Two reasons: a reader then needs one rule rather than two, and
`Rotulo` strings are not reliably sortable (`2.`, `2.1`, `IV`, `a)` do not order
by any single comparison).

**R-4 — renaming the nested emitter's id tokens to match the flat emitter's**,
so that invariant #11 could be asserted as identical id *strings*. Rejected:
§5.2's snippet fixes `pp1_agh1_agh1` for a section and `pp1_agh1_txt` for its
prose leaf, and Cycle 5's `agr` is fixed by 16 committed goldens. Renaming
either would contradict a ratified artifact to make a test easier. Invariant #11
is asserted on **text** and on **body segment URN structure** instead, with a
test pinning exactly where the two id schemes differ and why.
