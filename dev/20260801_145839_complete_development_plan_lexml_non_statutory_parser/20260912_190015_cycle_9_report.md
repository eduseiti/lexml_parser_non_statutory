## 1. Summary

**Verdict: complete.**

The plan's last cycle consolidates the regression suite and gives the parser the
instrument it needs for the 300+ documents it has never seen. Five things
landed: a `corpus` batch command whose report **reconciles as a checkable
property**, a coverage gate at 85% (measured 96.67%), a thin `Makefile`, a
**committed** mutation harness, and two environment gates that until now existed
only as manual procedures someone remembered to run.

**The suite is 6021 passed / 4 skipped / 2 deselected**, up from 5923, with all
143 goldens byte-identical and nothing modified under `lexml/`,
`lexml-proposed/`, `tests/golden/`, `tests/linker_fixtures/`,
`tests/referee_fixtures/` or `samples/`.

Four things are worth stating plainly, because each is a case of the method
catching something an argument would have missed:

1. **Four of the cycle's deliverables were over-specified, and asking was
   cheaper than building.** Taken literally, "promote all goldens to
   `tests/regression/`" is a 143-file move producing the exact unreviewable diff
   §9.4 exists to forbid. All four were escalated before implementation and
   settled as A-9.1–A-9.4.

2. **A mutation that fails to apply looks exactly like a mutation the suite
   caught.** Two of the ten silently mutated *nothing* on their first draft —
   one because `referee/__init__.py` shadows its own submodule, one because
   `generico.py` binds its helpers at import time. Both would have reported
   "caught" while never running. The harness now records *how* each was caught
   and distinguishes the project's own `AssertionError` from an incidental
   crash.

3. **The spec's own M-2 wording was insufficient**, and measurement is what
   revealed it. Dropping the `Bloco nome="vazio"` filler does **not** violate
   Constraint 2 — `ORDER_BLOCO` satisfies `minOccurs="1"` by itself — so the
   literal mutation would have produced valid output and been recorded as a
   **surviving** mutation: a false gap in the suite.

4. **A 251-vs-253 reference discrepancy looked like a defect and was not.** It
   decomposes exactly into `port_mf_277`'s route. My own first instruction to
   the test author would have pinned the wrong number; it was corrected
   mid-flight.

## 2. What was built

### New — `src/lexml_nonstat/corpus.py` (A-9.3)

```python
SUPPORTED_SUFFIXES: tuple[str, ...]        # from ingest.READERS, never restated

@dataclass(frozen=True)
class DocumentOutcome:
    source: str; ok: bool; urn: str = ""; profile: str = ""; route: str = ""
    emitter: str = ""; confidence: float = 0.0; flat: bool = True
    documents: int = 0; valid: bool | None = None
    blockers: tuple[str, ...] = (); warnings: tuple[str, ...] = ()
    references: int = 0; error: str = ""

@dataclass(frozen=True)
class CorpusReport:
    outcomes: tuple[DocumentOutcome, ...]; decisions: DecisionsReport
    # total · succeeded · failed · references · invalid · validated
    # by_route() · by_profile() · by_emitter() · by_blocker() · by_warning()
    # check() -> str | None        to_dict() -> dict

def walk_corpus(paths, *, limit=None) -> tuple[Path, ...]
def run_corpus(paths, *, emitter="auto", schema="both", generation=None,
               profile=None, referee=None, linker=None, validate_output=True,
               stop_on_error=False, limit=None) -> CorpusReport
def render_corpus_report(report: CorpusReport) -> str
```

`valid` is **tri-state on purpose**: `None` (not run) is a different fact from
`False`, and at 300 documents that difference decides whether "0 invalid" is
reassuring or meaningless. `SUPPORTED_SUFFIXES` is derived from the reader table
rather than restated — a hand-maintained copy would drift into looking like a
corpus that simply has no files of that kind.

## 6. The 251-vs-253 reference finding

A corpus run with `--linker=fixtures` resolves **251** references;
`tests/golden/generico_linked/` contains **253**. Measured per emitter:

| Rendering | primary | anexo1 | total |
|---|---|---|---|
| `port_mf_277` flat (`generico_linked/`) | 2 | 15 | 17 |
| `port_mf_277` statutory (`--emitter=auto`, its real route) | **0** | 15 | 15 |

`corpus` defaults to `--emitter=auto`, which follows the route, so the one
`norma`-routed sample is rendered statutorily and its **2 flat-primary
references are legitimately absent** — Cycle 8e's recorded open item **O-4**,
"`norma`'s `ParteInicial` is not linked". 253 = 251 + 2. Two tallies over two
different document sets, both correct.

The tests now pin **both**: 251 for `--emitter=auto`, built from the goldens
matching each document's *actual* route, and 253 for a forced
`--emitter=generico`, with the difference asserted as arithmetic so neither
tally can hide a drift inside the other.
