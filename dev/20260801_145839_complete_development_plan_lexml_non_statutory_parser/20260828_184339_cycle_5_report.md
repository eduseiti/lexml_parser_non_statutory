## 1. Summary

**Verdict: complete.**

The flat `generico` emitter is delivered, together with plan §3.1's `DocumentModel` and the
shared `render/` package that Cycles 5b and 6 will build on. All **15** samples — 16 documents,
counting `port_mf_277`'s annex — render, validate against **both** shipped schemas, conserve
every word of their source exactly once, carry unique ids, and satisfy Rules A and B. Goldens
are committed for all of them.

The cycle's substantive finding was not in the emitter but ahead of it. Cycle 3's front/back
matter renderers emit the *named parts*, while the segmentation covers the contiguous *hulls*:
**40 non-empty blocks in 6 of the 15 samples** sit inside a hull and inside no named part, and a
parts-based emitter loses all of them. Rendering *regions* instead (amendment **A-5.1**) closes
the hole without touching a line of Cycle 3's delivered behaviour.

Suite: **3510 pass / 0 fail**, up from a 3135-pass baseline — **375 new tests**. A 15-mutation
sweep over the new code killed **15 of 15**.

## 5. Changes to existing features

**No delivered behaviour changed.** Six additive changes, all logged in
[`20260828_184339_cycle_5_changes.md`](20260828_184339_cycle_5_changes.md): two private→public
promotions (`agrupamento_block`, `table_node`), three export additions, and a script-internal
refactor of `regen_goldens.py`'s `KINDS` contract. All 3135 inherited tests pass unmodified and
all 90 pre-existing golden files are byte-identical after regeneration.

**No major change was required, so none was escalated.** Five changes were considered and
deliberately rejected — most importantly, extending Cycle 3's `render_front_generico` with a
`residue=True` flag (it would put two behaviours behind one name and risk output that 25 tests
pin) and giving the front matter a distinct id token (it would change delivered ids *and* break
Rule A, whose prefix `pp1_fm` would not exist).

## 6. Deviations, findings and open items

1. **`back_region` and `render_back_generico` diverge semantically on 5 samples, by design.**
   Reported by subagent A. Two cases worth recording:
   - `adn_cst_10`'s signature is one source line, `JOSEFA MARIA COELHO MARQUES Em exercício`.
     Cycle 3 emits two `<p>` (parsed name and cargo); the region emits one `<p>`, the source block
     verbatim. Word-level conservation is identical.
   - `par_cosit_26`'s `Signature.span` covers only the name block, so the office line
     `Coordenador-Geral` is unclaimed and lands in the `nota` residue run. **The text is fully
     conserved** — the hull test proves it — but the office line is typed `nota` rather than
     `assinatura`. This is A-5.1 working as designed (an unclaimed block is rendered, whatever it
     is) rather than a defect, and it is cosmetic on the open route. **Cycle 6 is unaffected**:
     the `norma` route uses `render_parte_final`, which reads `Signature.cargo` directly. Worth
     revisiting if Cycle 7's segmentation comes to care about signature semantics.
2. **`test_agrupamento_block_matches_cycle3` is conditional, and must be.** `front_region` and
   `render_front_generico` *must* differ wherever a hull carries residue or a table — that
   difference is A-5.1's entire content. The test asserts byte equality for the 9 samples whose
   front hull is residue-free and table-free, and asserts **function identity**
   (`render.common.agrupamento_block is segment.render.agrupamento_block`) for all of them, which
   is the strongest available form of "one implementation, not two". Recorded in the spec as S-2.
3. **`DocumentModel` gained `decisions` mid-cycle** (spec amendment S-1). Plan §3.1 lists it and
   Cycle 4b already produces the records; determinism is asserted.
4. **`CARNE_LEAO`'s Word lists are all depth 1**, so the sample cannot discriminate a correct
   emitter from a flattening one. The synthetic three-level `ListNode` is the real guard — the
   A-1.3 / A-4.6 precedent, now for the third time.
5. **Conservation is checked over `PartePrincipal`, not the whole document.**
   `Metadado/MetadadoProprietario/campo` legitimately repeats source text (Cycle 2's A-2.2
   allowlist capture — e.g. `ad_pgfn_3`'s `JURISPRUDÊNCIA` list). `leaf_texts` never descends into
   `Metadado`, so nothing is double-counted; the test docstring states this rather than leaving it
   implicit.
6. **Nothing was left undone.** Every Cycle 5 bullet and test in the plan is discharged.
