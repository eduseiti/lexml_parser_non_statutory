## Change 1 — `python-docx` floor raised `>=1.0` → `>=1.1`

| Field | Content |
|---|---|
| **What changed** | `pyproject.toml`, `[project].dependencies` |
| **Before → after** | `python-docx>=1.0` → `python-docx>=1.1` |
| **Why** | `docx_reader.StyleResolver.name` uses `docx.styles.BabelFish` to map Word's internal style names (`"heading 1"`) onto the UI names the rest of the ecosystem uses (`"Heading 1"`). Without it, CARNE_LEAO's headings would be reported as `"heading 1"` and every downstream style test would have to special-case the casing. Verified against the installed 1.2.0. |
| **Blast radius** | None on code. A checkout pinned to exactly `python-docx==1.0` would now fail to resolve; no such pin exists in the repo. |
| **Plan impact** | None — the plan names `python-docx` without a version. |
| **Severity** | **Minor** — tightens an unconstrained floor to the API actually used. |

## Change 2 — Plan correction: the `parecer_93` indentation discriminator

| Field | Content |
|---|---|
| **What changed** | Plan §8 "Cycle 1", test bullet: *"indentation captured — the 21 quoted articles in `parecer_93` show `ind≈2880–2930` vs modal 0"* |
| **Before → after** | **Before:** quoted articles at ind≈2880–2930, **modal indent 0**. **After:** quoted articles at `w:ind/@w:left` ∈ {2880, 2908 ×18, 2930} — count and band confirmed exactly — but the modal indent is **not 0**. Body paragraphs carry *direct* `w:ind` values of 7–60, and the `Normal` style itself declares `w:ind/@w:left="2909"`. |
| **Why** | Measured with `python-docx` before implementation. 226 paragraphs carry no direct `w:ind`; of those, **219 are empty or section artifacts** and only one is a non-empty real paragraph. So the inherited 2909 is almost never load-bearing — but if indentation is resolved through style inheritance, the modal value becomes 2909, one twip from the quote band at 2908, and the discriminator collapses. |
| **Blast radius** | **Cycle 4's quotation guard**, which the plan builds on this signal (plan §2.5, §10 "Quoted statute misread as articulation — high, silent corruption"). A Cycle 4 implementation that reasoned from "modal 0" and resolved effective indent would have found the signal absent and silently degraded to the LLM referee or a flat fallback. |
| **Plan impact** | Amendment **A-1.1**. |
| **Severity** | **Minor** as a code change (no delivered behaviour existed), but the **most consequential finding of the cycle**: it corrects a factual claim that a later high-risk cycle depends on. Resolved with the user, who chose to record **both** `indent_direct` and `indent_effective` so Cycle 4 can pick whichever discriminates. |

### Consequence for the model

`StyledPara` carries two indentation fields rather than the plan's implied one:

- `indent_direct` — the paragraph's own `w:ind/@w:left` (or `@w:start`), `None` when absent.
- `indent_effective` — resolved through `pStyle` → `basedOn` chain → `docDefaults`.

Neither is sufficient alone; together they are lossless.

### One outlier, recorded so it is not mistaken for a defect

Of the 21 `Art.`-initial paragraphs, **20** sit in the 2880–2930 band. One does not: `Art. 4º - São atribuições do Advogado-Geral da União:` at `indent_direct=240`. The plan's "21 quoted articles" count is right; its implied "all 21 are deeply indented" is not. Cycle 4 must not assume indentation alone separates every quotation.

## Change 3 — Plan omission: struck runs, soft breaks and hyperlinks

| Field | Content |
|---|---|
| **What changed** | Plan §8 "Cycle 1" lists paragraphs, `pStyle`, `numPr`, `w:ind`, `w:jc`, runs and tables. It does not mention strikethrough, soft line breaks or hyperlinks. |
| **Before → after** | **Before:** unlisted, therefore unhandled. **After:** struck runs dropped (toggle-aware), paragraphs split at `<w:br/>`, hyperlink targets captured into `Inline.href`. |
| **Why** | All three occur in real samples: **18 struck runs** in `sumula_stj_125`, **11 hyperlinks** in CARNE_LEAO, **10 soft breaks** across `pn_cst_38` (7) and `par_cosit_26`/CARNE_LEAO (3 each). The Scala reference parser (`DOCXReader.stripStruckRuns`, `splitParAtSoftBreaks`) handles the first two, and Cycle 6b must round-trip against it. Left unhandled, struck text would be emitted as live text and soft-broken lines would silently merge — a heading with the paragraph beneath it. |
| **Blast radius** | Block counts differ from source paragraph counts wherever soft breaks occur: `pn_cst_38` 85→92, `par_cosit_26` 100→103, CARNE_LEAO 109→112. `StyledPara.index` is assigned **after** splitting and is the authoritative position; any later cycle correlating back to source paragraph numbers must account for this. |
| **Plan impact** | Amendment **A-1.2**. |
| **Severity** | **Minor** — additive handling of constructs the plan omitted. Confirmed with the user, who chose to mirror the reference parser and capture `href`. |

### Detail worth carrying forward

The 18 struck runs in `sumula_stj_125` are **ordinal markers inside otherwise-live sentences**: `ª` ×9, `º` ×8, `º,` ×1. Dropping them turns `(2ª T, 03.08.1994 — DJ 22.08.1994)` into `(2 T, 03.08.1994 — DJ 22.08.1994)`, and `art. 3º, § 4º` into `art. 3, § 4`. This matches the reference parser, but it is a real text change to a real sample — flagged here because it is invisible in a rendered document and would otherwise look like a bug in a future golden diff.

**Corrected during implementation, twice.** This entry first stated the struck runs were table-only; the golden agent's conservation work showed otherwise, and a direct count settled it: **7 in the table, 11 in body prose** (the agent reported 4/14, also wrong). The exemption's reach is therefore wider than "a quirk of one table" — it removes visible characters from body text in a real sample, which is exactly why `test_struck_text_absent_from_default_output` asserts the full round-trip: with `drop_strikethrough=False` the struck runs are conserved, proving the loss is bounded and reversible rather than merely intended.

The lesson generalises: **struck ordinals are a Portuguese legal-typography idiom**, not a one-document accident (authors strike the ordinal indicator to render `3º` as `3`). Cycle 9's corpus scale-out should expect them across the 300+ documents, and any cycle reasoning about article numbers must read the *dropped* form.

Strike stripping runs **before** soft-break splitting, following the reference parser's own comment: a struck run can contain `<w:br/>`-separated text, so splitting first would leave post-break segments outside the run's `<w:rPr>` and let struck text leak into the output.

## Change 4 — Plan correction: the NFC test cannot be written as specified

| Field | Content |
|---|---|
| **What changed** | Plan §8 "Cycle 1" test bullet: *"NFC unifies composed/decomposed accents"* |
| **Before → after** | **Before:** implies the samples exercise NFC normalisation. **After:** all 15 samples are **already NFC**, so a test run against them would pass with the normaliser deleted. NFC is tested against synthetic decomposed input instead, plus a standing assertion that the 15 samples are NFC-unchanged. |
| **Why** | Measured: `text == unicodedata.normalize("NFC", text)` holds for every sample. Also noted: the Scala `breakText` does **not** normalise — it only collapses whitespace. NFC is our deliberate addition, justified by the 300+ unseen corpus, where one decomposed `ç` would silently break profile regexes, the conservation invariant and byte-stable goldens at once. |
| **Blast radius** | Test design only. |
| **Plan impact** | Amendment **A-1.3**. |
| **Severity** | **Minor** — corrects an untestable-as-written criterion into one that bites. Resolved with the user (synthetic fixture + corpus tripwire). |

## Note — decisions taken without changing anything existing

Recorded because they shape what later cycles inherit, not because they altered delivered behaviour:

- **Empty paragraphs are retained** (`StyledPara.is_empty`). Cycle 3 may read blank lines as front/back-matter separators; dropping them at ingestion is irreversible.
- **Adjacent identically-formatted runs are merged.** Word splits runs on spell-check state, language and revision marks, so one sentence routinely arrives as a dozen runs. After merging, an `Inline` boundary marks a real formatting change — which is what Cycle 4's typography evidence reads.
- **`--dump-styled` ships as `python -m lexml_nonstat.ingest`**, mirroring Cycle 0's `python -m lexml_nonstat.validate`. The unified `cli.py` with a `dump-styled` subcommand remains Cycle 8's deliverable.
- **`StyledDoc.source` is a bare filename**, never a path, so goldens do not encode a checkout layout.
