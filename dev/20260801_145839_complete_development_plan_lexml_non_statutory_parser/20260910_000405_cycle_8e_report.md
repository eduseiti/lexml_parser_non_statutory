## 1. Summary

**Verdict: complete.**

The parser now resolves cited statutes to LexML URNs and emits them as
`<Remissao xlink:href="urn:lex:…">texto</Remissao>`. A new `refs/` subpackage
mirrors `referee/` module for module, calling the Haskell `linkertool` as a
long-lived co-process rather than porting its grammar. The linker is the
**third external thing this repository works without**: `--linker` defaults to
`none` everywhere, the binary is probed and never assumed, and the whole suite
is green with it absent.

Across the corpus the linker resolves **242 references, 120 distinct URNs, in
14 of the 15 samples**, all statutory — the measured gap A-L.8 asked for is in
§6.

Three things are worth stating plainly, because each is a case of the method
catching something an argument would have missed:

1. **A-L.9 was written from measurement, not adopted from the plan.** A-L.8
   predicted that the `;`-joined authorities and A-2.3's `0000` sentinels might
   be rejected by `parseURNLexML`. Both are fine. What is *not* fine is the
   **authority**, which every one of the 15 samples carries and which makes the
   linker return the input unchanged, silently, resolving nothing.
2. **45 % of the corpus's references live outside the body.** A body-only
   linker reached 210 of 379; two samples resolved zero. This was escalated and
   the user chose to thread the front/back-matter regions too.
3. **The conservation gate caught a real defect in this cycle's own code** —
   lxml's pretty-printer injecting three spaces into two `CARNE_LEAO`
   paragraphs, in a document valid on **both** schemas. A word-level comparison
   would have passed it; the character multiset A-L.4 requires did not.

**All 135 pre-existing goldens are byte-identical.** (The plan said 125; 135 is
the true count across the 9 pre-existing kinds, and the plan is corrected.)

## 2. What was built

### New subpackage — `src/lexml_nonstat/refs/`

| Module | Role |
|---|---|
| `protocol.py` | `Reference(start, end, urn, text)`, the `Linker` Protocol, and `DEFAULT_CONTEXT_URN` |
| `null.py` | `NullLinker` — resolves nothing, `enabled = False`. **The default everywhere** |
| `linkertool.py` | The co-process backend: `--hxml --xml --contexto=INLINE`, `###LEXML-END###` framing, `span/@xlink:href` harvested into verified character spans |
| `cache.py` | `LinkerCache` + `cache_key(context_urn, text)`; `read_only` for fixture directories |
| `probe.py` | `probe_linker() -> LinkerCapabilities`; never raises; searches `/usr/local/bin/linkertool` then `PATH` |
| `__init__.py` | `LINKER_MODES = ("none", "auto", "fixtures")`, `build_linker`, re-exports |

Public API as delivered:

```python
DEFAULT_CONTEXT_URN = "urn:lex:br:federal:lei:2000-01-01;1"
LINKER_MODES = ("none", "auto", "fixtures")

@dataclass(frozen=True, order=True)
class Reference: start: int; end: int; urn: str; text: str = ""

class Linker(Protocol):
    name: str
    def find_refs(self, text: str,
                  context_urn: str = DEFAULT_CONTEXT_URN) -> tuple[Reference, ...]: ...

def build_linker(mode: str = "none", **kwargs)
def probe_linker(binary=None) -> LinkerCapabilities
def cache_key(context_urn: str, text: str) -> str
class LinkerCache(directory, *, read_only=False)
class LinkertoolLinker(binary=None, *, cache=None, timeout=30.0)   # .spawns, .close()
```

## 6. The measured resolution rate (A-L.8, A-L.9)

Context `urn:lex:br:federal:lei:2000-01-01;1`, all 15 samples, 891 recorded
paragraphs.

**242 references · 120 distinct URNs · 175 paragraphs carrying at least one ·
14 of 15 samples.**

By norm type:

| Norm type | References |
|---|---|
| `lei` | 141 |
| `constituicao` | 74 |
| `decreto` | 8 |
| `emenda.constitucional` | 7 |
| `decreto.lei` | 6 |
| `lei.complementar` | 3 |
| `medida.provisoria` | 3 |

**What it cannot reach, and this is the point of measuring:** zero `portaria`,
zero `instrução normativa`, zero `parecer`, zero `ato declaratório`, zero
`solução de consulta`, zero `súmula` — *the genres this parser exists for*. The
grammar has no rule for any of them and its `súmula` rule is commented out
(`Regras2.hs:1009-1012`). `sumula_carf_42` resolves **nothing at all**, and is
committed as a golden in exactly that state.

So the linker covers the statutes our documents *cite*, and none of the
non-statutory acts they cite. A parecer citing another parecer stays unlinked.

**The context-URN finding (A-L.9)**, isolated component by component:

| Context URN component | Links? |
|---|---|
| `federal` authority | **yes** |
| non-statutory type (`parecer`, `ato.declaratorio`, `portaria`) | **yes** |
| A-2.3's `0000` year sentinel | **yes** |
| any non-`federal` authority (`ministerio.fazenda`, `;`-joined) | **NO — silently** |

All 15 samples carry a non-`federal` authority. The two things A-L.8 predicted
would break do not; the one it did not name does, and does so without an error.

## 8. Deviations and open items

| # | Item | Why, and what it blocks |
|---|---|---|
| O-1 | **`Remissao` is emitted for paragraphs only** — not table cells, not list items | Deliberate (spec N-5). The extractors were made read-through *everywhere* regardless, so widening later moves no golden and needs no re-measurement. Blocks nothing |
| O-2 | **`capabilities --format=json` does not report the linker** | `test_cli.py::test_capabilities_json_round_trips_the_probe` pins the JSON as a bare list of exactly `len(GENERATIONS)` schema records. Reporting the linker there would change a delivered output shape — a major change this cycle was not authorised to make. The **text** output reports it fully. A future cycle can reshape it deliberately |
| O-3 | **The pretty-print weakness is fixed only on the reference path** | An all-element `<p>` is serialised indented wherever it occurs, including in delivered goldens containing `<a>` or `<b>` alone. Fixing it generally would rewrite committed `generico` goldens for a cosmetic serialisation change — exactly the unreviewable diff §9.4 forbids. It is latent, not new, and it is now *documented* |
| O-4 | **`norma`'s `ParteInicial` is not linked** | It is built by Cycle 3's `render_parte_inicial`, outside this cycle's named call sites. One sample routes to `norma`, and its annex and body *are* linked. Small, and recorded |
| O-5 | **The linker reports no version** | The installed build prints a `cmdargs` banner with no version in it. Recorded as `""` and displayed as `unknown` rather than asserting something false. Nothing branches on it (invariant #12) |
| O-6 | **Whether a native Python recogniser should cover the non-statutory genres** | Deliberately left open by §18, and this cycle's §6 measurement is the evidence that question needed. **Not decided here** |
