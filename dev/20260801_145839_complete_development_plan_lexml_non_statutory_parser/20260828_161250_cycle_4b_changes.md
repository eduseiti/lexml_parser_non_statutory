### The probe document is not the obvious one

Worth recording because the obvious choice is wrong. Cycle 0's matrix case E is
`AgrupamentoHierarquico` containing a bare `<p>`, and it is invalid on the
shipped schemas — so it looks like the natural probe. It is invalid on
`lexml-proposed/` **too**: the maintainers' change adds `Agrupamento` and
`Bloco` to the choice, not `p`, which is exactly §5.4's constraint 3 ("prose
needs an `Agrupamento` wrapper"). Probing with case E would report "no
capability" against the very generation that has it.

The probe therefore uses `AgrupamentoHierarquico > Agrupamento > p`, measured
before a line was written:

| Generation | rigido | flexivel | ⇒ |
|---|---|---|---|
| `lexml/` | invalid | invalid | `nested_agrupamento = False` |
| `lexml-proposed/` | **valid** | **valid** | `nested_agrupamento = True` |

## Change considered and **rejected as major**

### Reporting `agreed + overrode == flagged` as the plan writes it

Plan §7.4's worked `--decisions-report` asserts

```
agreed + overrode == flagged
```

and the cycle's own test list repeats it. It is **false under the suite's own
default**: §9.3 pins `--referee=none` for every regression test, so flagged
decisions are never put to a referee and both terms are zero while `flagged` is
four. A referee may also abstain — a timeout, a malformed reply — which is
neither an agreement nor an override.

Three options were weighed:

1. **Force the identity** by counting an unconsulted flagged decision as an
   agreement. Rejected: it would report the rules as *confirmed* four times per
   corpus sweep when nothing confirmed them. That corrupts the one metric §7.4
   exists to produce.
2. **Weaken the test** to check only `rule_only + flagged == total`. Rejected
   under the cycle process — weakening a stated criterion to make code pass is
   exactly what requires escalation.
3. **Report two identities and amend the plan.** Chosen.

```
rule_only + flagged           == total
agreed + overrode + abstained == consulted        (consulted <= flagged)
```

The plan's form is the special case where every flagged decision is consulted
and none abstains, and it is asserted **in exactly that form** by
`test_plan_identity_holds_with_an_active_referee`, which runs the fixture
referee over all 15 samples and gets `agreed(4) + overrode(0) == flagged(4)`.
Amendment **A-4b.4**; `DecisionsReport.check()` names whichever identity broke
rather than merely returning false.

This was judged a plan correction rather than a behaviour change — no delivered
code or test was altered — and so was recorded rather than escalated. The
distinction from a major change is that nothing previously shipped moved.

## Addendum — three defects in this cycle's own code, found and fixed here

None of these touches previously-delivered behaviour: all three are in modules
first written by Cycle 4b, so fixing them is not a change to a shipped feature.
They are recorded here because the *way* they were found is the point.

Two were reported by the test-authoring subagent under the brief's
"report, do not fix" rule; the third was found by a mutation sweep. All three
were reproduced before being acted on.

### D-1 · `LocalReferee`'s JSON salvage was a greedy regex

`re.compile(r"\{.*\}", re.DOTALL)` spans from the **first** brace to the
**last**, not "the first balanced object" as its own comment claimed. Two
realistic outputs became abstentions:

```
'Aqui: {"verdict": "quoted", …}\n\nOutro exemplo: {"verdict": "own"}'
'Nota {ver anexo}: {"verdict": "quoted", …}'
```

Fail-safe (§7.3 c5) was never violated — nothing raised — but the fallback
referee would quietly stop answering, and `--decisions-report` would show it as
`abstained` rather than as the parse bug it was. Replaced by a balanced-brace
scan that yields every candidate and takes the first that parses into an
answer, tracking quotes and escapes so a brace inside a rationale does not
truncate it. Pinned by
`test_the_first_parseable_object_wins_not_the_greedy_span` (3 cases) and
`test_braces_inside_the_rationale_do_not_truncate_the_scan` (3 cases).

### D-2 · `LocalReferee`'s cache key used the model's basename

`cache_key(f"local:{self.model_path.name}", …)` against a docstring promising
"the model path is part of the key". `models/q4/qwen2.5-7b.gguf` and
`models/q8/qwen2.5-7b.gguf` — the ordinary quantisation layout — collided and
served each other's verdicts, **with `cache_hit` recorded in the telemetry to
say the answer was trustworthy**. Now keyed on the full path. Pinned by
`test_cache_key_separates_two_quantisations_of_the_same_file_name`.

### D-3 · `DecisionRecord.agreed` counted disagreement as agreement

The one that matters. `agreed` was implemented as *consulted, not abstained,
not overridden*. A referee that answers, **contradicts** the rule, and is
refused the override — because it is itself below `REFEREE_MIN_CONFIDENCE`,
which is reachable with the shipped constants — was reported as having agreed.

§7.4 reads that number as *"the rules were right but unsure"* and prescribes
tightening the thresholds when it is high. So the bug does not merely miscount:
it manufactures the specific evidence that would justify consulting the referee
*less*, out of the cases where the referee actually disagreed with the rules.

Fixed by defining `agreed` as *answered and said what the rule said*, adding an
`overruled` property and a fourth report bucket, and correcting the identity to
`agreed + overrode + overruled + abstained == consulted`. Plan §7.4 amended
(A-4b.4 extended).

Two tests written earlier in this same cycle pinned the wrong definition and
were updated, with the history kept in their docstrings —
`test_agreed_property` became `test_agreed_and_overruled_properties` (5 rows,
one per bucket) and `test_check_detects_a_broken_identity` gained the
four-term identity. No prior-cycle test was touched.

### Two branches the corpus cannot reach, now covered synthetically

The same sweep showed the corpus exercises 6 of `quotation_confidence`'s 8
branches. Unreachable, and therefore un-mutation-tested:

| branch | why no sample reaches it |
|---|---|
| `0.90` — in the quote band, no corroborating cue | every banded article in `parecer_93` *also* carries a citation antecedent, so all 23 take the 0.95 branch |
| `0.60` — acquitted, series not monotonic | the corpus's only acquitted articles are `port_mf_277`'s two, and its series is monotonic |

Both are now covered by synthetic tests, the A-1.3 / A-4.6 precedent for the
third time in this project. Neither is exotic: a block-quoted statute
introduced by a colon rather than by a named norm lands on the first, and if it
scored below the flag threshold every such paragraph in every such document
would become a referee question — turning a four-question corpus workload into
a per-document one.
