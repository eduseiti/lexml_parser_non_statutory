## Defects found in this cycle's own code, and fixed

### D-1 — a confirmed prose header silently disabled A-4.3's demotion

**Found by:** `test_an_adversarial_referee_does_not_move_sumula_stj_125`, on its
first run. Exactly the test written to catch overreach.

`demote_numbered_containers` collects a run as *a maximal stretch of
same-depth assignments with `style is not None`*. A confirmed prose header has
`style is None`, so one landing between two `Heading 1` blocks **split the run
in half**, and neither half met `MIN_DEMOTION_RUN`. On `sumula_stj_125` under
an adversarial referee this undid A-4.3 completely: its 7 cases × 4 styled
subsections became **48 top-level sections**.

The fix steps over prose-form entries when collecting the run, rather than
letting them terminate it. They are never themselves demoted — they are already
positioned relative to the styled heading above them.

**Why it matters beyond the attack:** this was reachable with the *real*
fixtures too, on any document mixing styled headings with a confirmed prose
header. `sumula_stj_125` is that document; it was one confirmed candidate away.

### D-2 — a confirmed prose header could outrank a styled one

**Found by:** the same test, after D-1 was fixed (48 → 13, still wrong).

The first implementation opened every confirmed header at depth 1, clearing the
stack. On a document where Word *does* declare outline levels, that put the
header above the author's own structure — publication dates parenting the case
subsections.

Fixed by anchoring: a confirmed header opens **directly beneath the innermost
styled section still open**, and reaches depth 1 only when there is none —
which is the `par_cosit_26` case the amendment was written for. Word's
declaration is the stronger evidence and a referee's answer may add a level
inside it, never displace it. After the fix, `sumula_stj_125` holds at 7
top-level sections *even under an adversarial referee answering `secao` at 1.0*.

### D-3 — 12 fixtures recorded truncated context in their metadata

**Found by:** `test_every_heading_fixture_is_reachable`.

The generator script wrote `meta.ctx`/`meta.next_ctx` truncated to 200
characters while hashing the full strings. The filenames were correct — the
cache worked — but the files were not self-describing, so the key could not be
re-derived from the file's own contents. Rewritten with the full strings, and
every key re-verified by replay (the A-C.4 method).

## Changes considered and **rejected**

| Considered | Rejected because |
|---|---|
| Relaxing `test_sumula_stj_125_is_unchanged_by_the_referee` to let the tree change | The first failure looked like an over-strict test, and treating it as one would have hidden **D-1 and D-2**. The right move was to read the tree: 48 sections is not a strict test failing, it is the styled structure collapsing. The test was then *sharpened* — "the styled tree is untouched and the addition lands inside it" — rather than loosened |
| Lowering `MIN_SECTIONS_FOR_FULL_CONFIDENCE`, or exempting confirmed headers from damping, so `sumula_carf_42`'s single confirmed header makes it structured | A document does not have a structure on the strength of one heading. The rule that has always refused a lone rótulo must refuse a lone confirmed header; a referee gets no exemption from invariant #8. Pinned as `test_a_lone_confirmed_header_does_not_make_a_document_structured` |
| A deterministic pre-filter for `Fl. n` / footer artifacts inside this cycle's generator | Pre-empts design decisions belonging to `docs/20260830_205825_…`. The referee refuses all 13 correctly, so this is a cost question, not a correctness one. **Deferred by the user's answer to Q-4** |
| Letting the referee volunteer headers the generator did not propose | Invariant #8 would stop being structural. **Rejected by the user's answer to Q-2** |
| Making `next_ctx` unconditional in `cache_key` | Would move all 7 existing fixture keys for no gain, re-running A-C.4's re-keying exercise as pure cost |
| Recording the 31 fixtures by pointing the CLI at a live provider | Would have written `meta` without the provenance line and made the run's honesty depend on a key being present. The verdicts *are* live-measured (probe, §5 of the record) and transcribed; `meta.origin` says exactly that, distinguishing them from the 7 hand-authored ones |
