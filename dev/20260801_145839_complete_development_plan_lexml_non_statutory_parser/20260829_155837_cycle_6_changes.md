## C-2 — `render/common.py::leaf_texts` reads four statutory elements, and skips a `Caput`'s echoed `Rotulo`

| Field | Content |
|---|---|
| **What changed** | `_WHOLE_TEXT_TAGS` gains `Epigrafe`, `Ementa`, `NomePessoa`, `Cargo`. New `_ECHOED_ROTULO_PARENTS = {"Caput"}` makes `leaf_texts` skip a `Rotulo` whose parent is a `Caput` |
| **Before → after** | Before: a `Norma`'s epigraph, ementa and signatures were **not extracted at all**, and a `Caput`'s rótulo was counted twice. Measured on `port_mf_277`: 29 words unread, 4 counted twice. After: the bundle's word multiset equals the source's exactly |
| **Why** | The §4.2 conservation gate refused the statutory render of the corpus's one statutory document. The defect was in extraction, not in the emitter: `leaf_texts` was written for `generico`, where none of these five elements can occur |
| **Blast radius** | None on delivered output. All four added tags are declared **only** inside `HierarchicalStructure`, so no `generico` or `generico-aninhado` document can contain one — confirmed by all 32 goldens and 3957 prior tests staying green |
| **Plan impact** | New amendment **A-6.4** |

**Escalated and approved.** The `Caput` half is a conservation-invariant
question, not a refactor: it decides what "the source said it once" means when
the reference convention writes a rótulo twice. Three options were put to the
user — skip the copy, stop emitting it, or let every statutory render fail
conservation. The user chose skipping the copy, which keeps §4.3's shape and
the reference parser's convention intact.

The precedent is exact and already in this module: `Bloco nome="nivel"` is
excluded from extraction because it carries a value *this package inferred*
rather than text the source contained, pinned by
`test_leaf_texts_skips_structural_markers`. A `Caput`'s `Rotulo` is the same
category — the emitter wrote it, the document said it once.

## Changes considered and rejected

**1. Extending `render/ids.py` with a dispositivo mode.** Rejected as the wrong
shape, not as too large. `IdAllocator`'s docstring ratifies the path scheme and
its `child()` contract *composes an id from a parent it has issued* — which is
precisely what `lexml09-flexivel`'s `idArtigo` pattern forbids. One module
answering to two incompatible grammars would make Rule A's "structural rather
than aspirational" guarantee conditional on which method a caller happened to
use. A separate `DispositivoIds` keeps both invariants exact. *(Spec Q-1,
confirmed with the user.)*

**2. Dropping the `Caput`'s `Rotulo` from the output.** Probed valid (a `Caput`
without a `Rotulo` is accepted by both schemas), and it would have made the
conservation problem disappear with no extraction change. Rejected: §5.3 says
this emitter matches the reference parser's conventions, §4.3's snippet writes
the rótulo twice, and changing the artifact to avoid changing a measurement is
the wrong way round. *(Escalated with C-2; the user chose the extraction fix.)*

**3. Rendering front/back matter as *regions* on the statutory route.** This is
what amendment A-5.1 forced for `generico`, and it is **not possible here**:
`ParteInicial` and `ParteFinal` are closed `xsd:sequence`s that reject both
`<Agrupamento>` and bare `<p>` (probes B5, B13, B14). Rather than weaken A-5.1,
Cycle 6 folds front residue into `Preambulo` and **falls back** on back residue.
*(Spec Q-2, decided with the user — recorded as A-6.2.)*

**4. Gating the fallback on schema validity alone**, as §4.2's sentence reads
most literally. Rejected: no schema can detect lost text, so a *valid* document
that dropped a paragraph would publish silently — and this cycle's own first
statutory render was exactly that document. Conservation and coverage join
validity in the gate. *(Spec Q-4, decided with the user — recorded as A-6.3.)*

**5. Selecting the annex's nested form from the capability probe.** The literal
reading of A-R.8. Rejected: emitted output would then depend on which
directories exist on the machine, breaking determinism (§9.2) and making the
goldens un-committable. The form is an explicit flag; A-R.8 is discharged by
tests. *(Spec Q-6, decided with the user.)*

**6. Building `Alinea` and `Item`.** No corpus document reaches them, so no
test could discharge them — the reasoning that kept `nota_tecnica` unbuilt in
A-2.4. A document needing them falls back to `generico`, which loses no text.
