# Cycle 3 Changes — changes to already-delivered features

- **Cycle:** 3 — Front/back matter segmentation
- **Date:** 2026-08-28
- **Spec:** `20260828_011822_cycle_3_spec.md`

Cycle 3 is **additive**: no previously-delivered behaviour, output shape or
test was changed, and all 788 tests from Cycles 0–2 pass unmodified. The
changes below are extensions to existing modules, each minor under the cycle
process's definition (new optional fields, new branch that does not alter
existing outcomes).

## Changes deliberately **not** made

### `tests/unit/matrix_cases.py` was left alone — considered and rejected

The spec's implementation plan item 9 proposed adding the A-3.2
`textoSimplesType` findings to the §2.1 encoding matrix. On inspection this
would have been a **major change to a Cycle 0 regression test**:
`MATRIX` mirrors the plan's §2.1 table row for row, and
`test_matrix_dimensions` pins `len(MATRIX) == PLAN_ROW_COUNT == 16`. Adding
rows means either breaking that assertion or editing a Cycle 0 test to
accommodate this cycle — exactly what the cycle process requires confirmation
for.

The findings are pinned instead in `tests/unit/test_segment_render.py`, which
is this cycle's own file. Nothing is lost: a schema revision that changed the
`textoSimplesType` requirement still breaks a test loudly.

### The plan's §4.3 snippet was **not** corrected — it is valid

The spec's reconciliation Q2 recorded, and the user approved, amending §4.3 on
the grounds that its `LocalDataFecho` example was invalid. Re-checking during
implementation showed the snippet **carries no `LocalDataFecho` at all** — it
was re-validated verbatim against both schemas during this cycle and passes.

The A-3.2 constraint is real and load-bearing (this cycle's renderer emits the
closing line, and would have failed validation without it), so the amendment
was written — but as a **newly discovered constraint** rather than as a
correction to a plan error, and A-3.2 says so explicitly. Recorded here because
the spec's stated reason for the amendment did not survive verification, even
though the amendment itself did.
