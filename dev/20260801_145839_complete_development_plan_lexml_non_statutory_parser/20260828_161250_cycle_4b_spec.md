### 2.2 Non-blocking decisions taken here

- **D-1 — `blockers` is a tuple of `Blocker(code, detail, vetoes)`, not `list[str]`.**
  §4.1 types it `list[str]`. A bare string cannot say *whether the blocker
  vetoes the statutory route*, and A-R.7 requires exactly that distinction:
  `nested_unavailable` is recorded on the verdict but **must not change the
  route**. Codes are module constants so tests and telemetry name them rather
  than matching prose. `blocker_codes` gives the plan's flat view back.
- **D-2 — the verdict carries `articles_own` as a property**, `articles_found -
  articles_quoted`. It is the single number the route turns on and deserves a
  name.
- **D-3 — 4b flags two decision kinds: `route` and `own_articulation`.**
  `is_heading` and `section_kind` are on the `Referee` protocol as §7.3
  requires and are unit-tested against every implementation, but nothing in the
  pipeline consults them yet — there is no decision in Cycles 0–4b that asks
  them. Wiring them belongs to whichever cycle needs a section *name*.
- **D-4 — the `own_articulation` confidence is derived from Cycle 4's cues, not
  from a new analysis.** `quotation_confidence()` reads `bands.contains`,
  `omissis`, `citation_antecedent`, `quoted` and `article_monotonic` off the
  `QuotationAnalysis` and weighs them. It never re-decides who is quoted.
- **D-5 — a fifth golden kind, `routing`.** Every prior cycle added one; it is
  what pins the §4.4 route table byte-stably rather than only as assertions.
- **D-6 — `python3 -m lexml_nonstat.routing` carries `--decisions-report`**,
  mirroring Cycles 1–3's per-package `__main__`. Cycle 8 still owns `cli.py`.
- **D-7 — test file organisation:** one file per module cluster, listed in §6.

### 2.3 Ambiguity found in the cycle text, resolved here

**The plan's `--decisions-report` reconciliation identity is wrong under the
suite's own default.** §7.4 asserts `agreed + overrode == flagged`. Under
`--referee=none` — which §9.3 pins for every regression test — flagged
decisions are never put to a referee, so `agreed + overrode == 0 < flagged`.
The identity holds only over decisions actually *consulted*, and a referee may
also **abstain** (malformed JSON, timeout, `NullReferee`). The report therefore
reconciles two identities, and this is recorded as amendment **A-4b.4**:

```
rule_only + flagged            == total
agreed + overrode + abstained  == consulted        (consulted <= flagged)
```

The plan's form is the special case where every flagged decision is consulted
and none abstains; the fixture-referee test asserts it in exactly that form.

### 3.1 `src/lexml_nonstat/routing/`

```python
# genre.py — §2.7: priors, never rules
@dataclass(frozen=True)
class GenrePrior:
    profile: str
    p_norma: float          # prior probability the genre is articulated
    note: str

# coverage.py — the census, read off Cycle 4's analysis
@dataclass(frozen=True)
class ArticleCensus:
    found: tuple[int, ...]          # every body index starting `Art. N`
    quoted: tuple[int, ...]         # those the Cycle 4 guard convicted

    monotonic: bool

# viability.py — §4.1
@dataclass(frozen=True)
class Blocker:
    code: str
    detail: str
    vetoes: bool = True

@dataclass(frozen=True)
class StatutoryViability:
    route: Literal["norma", "generico"]
    confidence: float
    articles_found: int
    articles_quoted: int
    numbering_monotonic: bool
    coverage: float
    has_anexos: bool
    blockers: tuple[Blocker, ...] = ()
    evidence: dict[str, Any] = field(default_factory=dict)
    referee_consulted: bool = False
    referee_overrode: bool = False
    source: str | None = None
    profile: str | None = None
    # properties: articles_own, blocker_codes, has_blocker(code), is_statutory
    # to_dict / to_json / from_dict / from_json  (Cycle 1–4 house style)

def assess_viability(
    doc, *, segmentation=None, profile=None, metadata=None, hierarchy=None,
    referee=None, log=None, emitter="generico", generation="shipped",
) -> StatutoryViability: ...
```

**Gates (§4.2).** `route == "norma"` iff **all** hold:

| Gate | Constant | Rationale |
|---|---|---|
| `articles_own >= 1` | `MIN_OWN_ARTICLES` | nothing to articulate otherwise |
| `numbering_monotonic` | — | §2.6's third cue |
| `coverage >= 0.6` | `COVERAGE_MIN` | §4.2 "covers most of the body" |
| no vetoing blocker | — | §4.1 |

`coverage` is measured **after the annex split** (§4.2), over the body span
alone: the fraction of body blocks at or after the first own article.
`port_mf_277`'s body is exactly its two articles ⇒ `1.0`.

**Blocker vocabulary.**

| Code | Vetoes | Fires when |
|---|---|---|
| `no_articles` | yes | zero `Art. N` in the body |
| `all_articles_quoted` | yes | articles found, every one convicted — `parecer_93` (25/25), `par_cosit_26` (5/5) |
| `non_monotonic_series` | yes | the census series does not hold together |
| `low_coverage` | yes | `coverage < COVERAGE_MIN` |
| `top_level_table` | yes | a table sits in the body outside any dispositivo |
| `nested_unavailable` | **no** | `emitter="generico-aninhado"` against a generation whose probe says no. **A-R.7: the route is unchanged** |

**Confidence.** `p_norma` starts at the genre prior and is moved by named
contributions, every one recorded in `evidence["contributions"]`; the verdict's
`confidence` is `p_norma` on the `norma` route and `1 - p_norma` on `generico`,
so it always reads as confidence *in the route chosen*.

### 3.2 `src/lexml_nonstat/referee/`

```python
# protocol.py
@dataclass(frozen=True)
class Verdict:
    verdict: str | None          # None == abstained
    confidence: float = 0.0
    rationale: str = ""
    @property
    def abstained(self) -> bool

class Referee(Protocol):
    name: str
    def is_own_articulation(self, excerpt: str, ctx: str) -> Verdict: ...   # "own" | "quoted"
    def is_heading(self, para: str, ctx: str) -> Verdict: ...               # "heading" | "prose"
    def section_kind(self, label: str, heading: str) -> Verdict: ...        # a SECTION_KINDS value

# null.py       NullReferee     — abstains on everything, never consulted, no network
# cache.py      RefereeCache    — disk, keyed by sha256(model, kind, excerpt, ctx); read_only mode
# prompts.py    build_prompt(kind, excerpt, ctx) -> tuple[str, str]; MAX_EXCERPT_CHARS = 1200
# api.py        CachedAPIReferee(model, base_url, api_key=None, cache=None, transport=None, timeout=30)
# local.py      LocalReferee(model_path, binary="llama-cli", runner=None, timeout=120)
# adjudicate.py adjudicate(kind, locator, doc, rule_verdict, rule_confidence,
#                          excerpt, ctx, referee=None, log=None) -> tuple[Any, DecisionRecord]
```

Design constraints from §7.3, each with a test in §6:

1. **Rules first** — `adjudicate` consults only when `rule_confidence < FLAG_THRESHOLD` (0.6).
2. **Structured output only** — the API referee accepts strictly
   `{"verdict","confidence","rationale"}`; anything else abstains.
3. **Disk-cached by excerpt hash** — a hit performs zero transport calls.
4. **Advisory** — a referee verdict is applied only when
   `rule_confidence < RULE_HIGH_CONFIDENCE` (0.75) *and*
   `referee.confidence >= REFEREE_MIN_CONFIDENCE` (0.6). Invariant #9.
5. **Fail-safe** — transport error, timeout, non-JSON, wrong schema, missing
   binary ⇒ abstain, keep the rule verdict, log `WARN`. Never raises.
6. **Fully logged** — §3.3.
7. **`--referee=none|api|local`**, default `none`; the suite pins `none`.

### 3.4 `src/lexml_nonstat/validate/schema.py` — minimal probe (A-R.2, partial)

Additive and keyword-only; every existing call keeps its meaning.

```python
SHIPPED = "shipped"; PROPOSED = "proposed"
def generation_dir(generation: str = SHIPPED) -> Path        # lexml/ | lexml-proposed/
def load_schema(name, *, generation=SHIPPED, use_cache=True)  # cache key gains the generation
```

**The probe probes.** It validates a minimal document — the shape §5.4

| Generation | rigido | flexivel | ⇒ `nested_agrupamento` |
|---|---|---|---|
| `lexml/` (shipped) | invalid | invalid | `False` |
| `lexml-proposed/` | **valid** | **valid** | `True` |

An absent generation directory yields `available=False`, `nested_agrupamento=False`
and a diagnostic naming the missing directory — never an exception (invariant #12:
the suite must stay green against `lexml/` alone).

## 8. Risks

| Risk | Mitigation |
|---|---|
| **The route discriminator is trivially right on 15 samples.** `own_articles > 0` alone reproduces the table; a rule tuned to that would fail on the 285 unseen documents. | The verdict is built from the full evidence set §4.1 names — census, monotonicity, coverage, genre prior, blockers — and every gate has a synthetic test that fires it independently of the corpus. The A-1.3/A-4.6 precedent: what the corpus cannot reach is tested synthetically. |
| **`routing/` becomes a second source of truth for quotation.** | Structural: `census()` takes a `QuotationAnalysis` and reads it. A test asserts the census tracks the analysis rather than recomputing it. |
| **A referee could flip the route.** | Invariant #9 plus the adversarial test: a referee answering "own" to everything leaves every sample's route unchanged. |
| **Pulling the probe forward breaks Cycle 0's 107 tests.** | Keyword-only, shipped default, cache key widened internally. Any required edit to a Cycle 0 test is escalated, not absorbed. |
| **The hand-authored fixture encodes what we want to hear.** | It is documented as synthetic in `tests/referee_fixtures/README.md`, with the refresh command; and the test it feeds asserts *agreement with an already-correct rule verdict*, so a wrong fixture would show up as a spurious override, not a silent pass. |
| **`--decisions-report` identities.** | The plan's identity is wrong under `--referee=none` (§2.3); both correct identities are asserted, and the plan is amended rather than the test weakened. |
