## 2. Reconciliation outcomes

Four load-bearing points were not settled by the plan text. All four were put to
the user; all four answers are recorded here and are binding.

### Q1 — What does the segmenter emit? → **Typed model + both renderings**

The plan's Cycle 3 test list ends with "`ParteInicial`/`ParteFinal` fragments
validate on both schemas". A schema probe run this cycle shows that bullet
cannot be the whole story:

```
INVALID  DocumentoGenerico + ParteInicial
  [rigido]   Element 'ParteInicial': This element is not expected.
             Expected is one of ( PartePrincipal, Anexos )
  [flexivel] (same)
```

`ParteInicial`/`ParteFinal` live in `HierarchicalStructure` (`Norma`) only —
`OpenStructure` (`DocumentoGenerico`) has no slot for them. Per plan §4.4, **14
of the 15 samples route to `generico`**, so a Cycle 3 that emitted only
`ParteInicial` would have produced front matter that 14 samples cannot carry.

**Decision:** Cycle 3 delivers a rendering-agnostic model plus *two* verified
renderings, in keeping with §3.1's rendering-agnostic design:

| Route | Rendering | Probe |
|---|---|---|
| `norma` (Cycle 6) | `<ParteInicial>`/`<ParteFinal>` proper | VALID on both |
| `generico` (Cycle 5) | `<Agrupamento nome="epigrafe"\|"ementa"\|…>` | VALID on both |

Cycle 3 owns the model and the two *fragment builders*; Cycles 5/6 own placing
them in a whole document.

### Q2 — Plan §4.3's snippet is invalid → **amend the plan, use the verified shape**

The probe rejects the plan's own §4.3 example:

```
INVALID  <LocalDataFecho>Brasília, 7 de junho de 2018.</LocalDataFecho>
  [rigido] Element 'LocalDataFecho': The attribute 'id' is required but missing.
  [rigido] Element 'LocalDataFecho': Character content other than whitespace is
           not allowed because the content type is 'element-only'
```

`LocalDataFecho` and `FormulaPromulgacao` are `textoSimplesType`: they require
an `id` **and** `<p>` wrapping. Bare `<Epigrafe>` is likewise rejected — `id` is
required there too. Verified correct shape:

```xml
<LocalDataFecho id="ldf1"><p>Brasília, 7 de junho de 2018.</p></LocalDataFecho>
```

**Decision:** correct §4.3 in place, add amendment **A-3.2**, implement the
verified shape, and pin the finding with new schema-matrix cases so a schema
revision breaks a test rather than silently invalidating output.

### Q3 — Annex detection → **profile-gated, following the A-2.2 precedent**

`sumula_stj_125` block 369 is a bare paragraph `ANEXO`, in a court-precedent
compilation with no annex; `port_mf_277` block 6 is a genuine `ANEXO ÚNICO`. A
naive `^ANEXO` rule fires on both.

**Decision:** annex patterns are a per-profile field (`annex_res`), empty for
`jurisprudencia_generico` and `servico`. This is exactly the A-2.2 reasoning
already ratified for `MetadadoProprietario`: a missed annex is recoverable —
the text stays in the body — whereas a false annex silently amputates the
document.

### Q4 — Multiple signature blocks → **detect all, in document order**

`parecer_93` carries the parecer's own signature (428–430) *and* an appended
`DESPACHO DO CONSULTOR-GERAL` with its own header, NUP, date and signer
(437–449). Suppressing either loses text and breaks the conservation invariant.

**Decision:** `BackMatter.signatures` is an ordered tuple of every detected
block, each with its `source_indices`. Cycle 3 reports evidence; Cycles 4–6
decide rendering. This follows §3.1's "keep evidence, not conclusions".

### Non-blocking decisions taken without asking

1. **Package name is `segment/`**, per plan §3's layout, with modules
   `frontmatter.py`, `backmatter.py`, `fields.py`, `sections.py` — except that
   `fields.py` is **not created**: labelled-field capture already shipped in
   Cycle 2's `model/metadata.py` under the ratified A-2.2 allowlist, and a
   second implementation would be a competing source of truth. Recorded as
   amendment **A-3.4**; `segment/` instead re-exports the Cycle 2 result.
2. **`sections.py` holds the body/annex boundary split only** — hierarchy
   inference inside the body is Cycle 4's, not this cycle's.
3. **Person-name discrimination lives in `backmatter.py`** as
   `looks_like_person_name()`, prototyped and verified 23/23 against the corpus
   before writing this spec (§7 risk 1).
4. Test files: `tests/unit/test_segment_frontmatter.py`,
   `test_segment_backmatter.py`, `test_segment_sections.py`,
   `test_segment_render.py`, and `tests/golden/test_segment_goldens.py`.
5. Golden kind name is `segment`, wired into `scripts/regen_goldens.py`
   alongside `styled` and `metadata`.

## 3. Expanded goals

### 3.1 New package `src/lexml_nonstat/segment/`

```
segment/
  __init__.py       public surface
  model.py          the typed segmentation model
  frontmatter.py    epigraph, ementa, preamble, enacting formula
  backmatter.py     local/date closing, signatures, person-name discriminator
  sections.py       body/annex boundary split
  render.py         the two verified renderings (Q1)
  __main__.py       python -m lexml_nonstat.segment
```

### 3.2 Public API — exact signatures

```python
# segment/model.py
@dataclass(frozen=True)
class Span:
    """A contiguous run of source blocks, kept as indices so nothing is copied."""
    start: int
    end: int                      # inclusive
    @property
    def indices(self) -> tuple[int, ...]: ...
    def __contains__(self, index: int) -> bool: ...

@dataclass(frozen=True)
class FrontMatter:
    epigraph: Span | None = None
    ementa: Span | None = None
    preamble: Span | None = None
    enacting_formula: Span | None = None   # DECLARA / RESOLVE:
    fields: tuple[ProprietaryField, ...] = ()   # from Cycle 2, re-exported
    @property
    def span(self) -> Span | None: ...     # hull of all present parts
    @property
    def is_empty(self) -> bool: ...

@dataclass(frozen=True)
class Signature:
    name: str
    cargo: str | None = None
    local_date: str | None = None
    span: Span = ...
    date: UrnDate | None = None            # parsed from local_date when possible

@dataclass(frozen=True)
class BackMatter:
    signatures: tuple[Signature, ...] = ()
    local_date: Span | None = None
    @property
    def is_empty(self) -> bool: ...

@dataclass(frozen=True)
class Annex:
    label: str                             # "ANEXO ÚNICO", "ANEXO I"
    span: Span
    ordinal: int                           # 1-based, for the !anexoN fragment

@dataclass(frozen=True)
class Segmentation:
    front: FrontMatter
    body: Span | None
    back: BackMatter
    annexes: tuple[Annex, ...] = ()
    source: str | None = None
    profile: str | None = None
    def to_dict(self) -> dict: ...
    def to_json(self, *, indent: int = 2) -> str: ...
    @classmethod
    def from_dict(cls, data: dict) -> "Segmentation": ...
    @classmethod
    def from_json(cls, text: str) -> "Segmentation": ...
    @property
    def covered(self) -> frozenset[int]: ...   # every block index accounted for

# segment/__init__.py
def segment_document(
    doc: StyledDoc, *, profile: DocumentProfile | None = None,
    metadata: Metadata | None = None,
) -> Segmentation: ...

# segment/render.py
def render_parte_inicial(front, doc, *, prefix="") -> etree._Element | None
def render_parte_final(back, doc, *, prefix="") -> etree._Element | None
def render_front_generico(front, doc, *, prefix="pp1") -> tuple[etree._Element, ...]
def render_back_generico(back, doc, *, prefix="pp1") -> tuple[etree._Element, ...]
```

`segment_document` never raises: a document with no front or back matter yields
an empty `FrontMatter`/`BackMatter` and a `body` covering everything.

Per Q3, `annex_res` is empty for `jurisprudencia_generico` and `servico`.

## 6. Risks

| Risk | Likelihood | Mitigation |
|---|---|---|
| Signature heuristic over-fires on institution names | **high** — measured: a naive ALL-CAPS rule produces 6 false positives | `looks_like_person_name()` with a non-name vocabulary, prototyped 23/23 before coding; explicit rejection tests |
| Annex rule amputates a document (`sumula_stj_125`) | high | profile-gated per Q3; dedicated regression test |
| `adn_cst_10` portal artifact captured as ementa | high | explicit rejection pattern + test |
| Extending `DocumentProfile` breaks Cycle 2 tests | medium | additive fields with `()` defaults; full suite re-run |
| Rules tuned to 15 samples generalise badly to 300+ | medium | genre-agnostic evidence (labels, position, style, alignment) preferred over sample-specific literals; profile gating keeps recall bounded rather than guessing |
| `port_mf_277` signer precedes its annex | low | annex split runs **before** signature detection; pinned by `test_signature_before_annex_still_found` |
