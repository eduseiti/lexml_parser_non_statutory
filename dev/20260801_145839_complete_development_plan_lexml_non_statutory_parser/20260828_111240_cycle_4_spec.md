## 3. Reconciliation outcomes

### Questions put to the user (answers binding)

| # | Question | Answer |
|---|---|---|
| R-1 | `sumula_stj_125`: group the 38 same-level `Heading 1` blocks, or keep them flat? | **Group by case** — 8 parents × 4–5 children. *Against the spec author's recommendation;* the mechanism must therefore be genre-agnostic (see A-4.3). |
| R-2 | Infer over the body span only, or body + each annex? | **Body + each annex, separate trees.** Discharges A-R.8 early. |
| R-3 | How is `Section.kind` assigned? | **Derived from label form + depth**: `secao`/`subsecao`/`item` for dotted numerics by depth, `inciso` for roman, `alinea` for alpha, `capitulo`/`titulo`/`secao`/`subsecao` for named units, `agrupamento` for unlabelled/style-only. |
| R-4 | How is "trees matching hand-authored goldens" discharged? | **Both**: a regenerated-and-reviewed `hierarchy` golden kind *and* a hand-written ground-truth table asserted independently. |

### Decisions taken here without asking (non-blocking)

| # | Decision | Reasoning |
|---|---|---|
| D-1 | Content nodes (`Para`, `ListNode`, `ListItem`, `Table`, `Section`) live in **`model/nodes.py`**, per plan §3.1's MODEL layer; `hierarchy/` builds them. | The plan locates them there; `hierarchy/` is the inference, not the model. |
| D-2 | `Inline` is **re-used from `ingest.styled`**, not re-declared. | Identical field-for-field to §3.1's `Inline`; a second copy would be two sources of truth for the same frozen record. |
| D-3 | `artigo`/`paragrafo` labels (`Art. 1º`, `§ 2º`, `Parágrafo único`) are **recognised by the grammar but never create a `Section`.** | Articulation is the `norma` route's shape (Cycles 4b/6). | D-5 | Quoted paragraphs stay in the tree as `Para(kind="quote")` in the enclosing section's body. | Conservation (invariant #2). A guard that *drops* text would trade one failure for a worse one. |

### Plan divergences to record as amendments

| ID | Divergence |
|---|---|
| A-4.1 | The plan's `quotation.py` design ("indentation") cannot use a plain modal-deviation test: in `parecer_93` the quote band (2908) is **one twip below** the modal body indent (2909). The discriminator is **declared-vs-inherited**: the modal body indent is *inherited from the style*, while every quoted paragraph *declares* its own. Quote-band detection therefore has two rules, and picks whichever applies. |
| A-4.2 | The plan's label grammar needs three **negative** rules it does not list, each forced by a real sample: a component of `0`/`00` is not an ordinal (`2.08.30.00`); a dotted label whose parent prefix was never opened is not a label (`1.24.20.25`, `29.11`); and a **top-level numeric series must start at 1 or 2 and increase by ≤3**, or the whole series is rejected (`parecer_93`'s `111, 46, 194, 74`). |
| A-4.3 | R-1's grouping is implemented as **numbered-container demotion**, not a vocabulary rule: within a run of same-level style headings that starts with a heading carrying its own identifier, identifier-free headings demote one level under the nearest preceding identifier-bearing heading. Fires on `sumula_stj_125` (8 numbered + 30 bare); does **not** fire on `CARNE_LEAO` (0 numbered) or on `port_mf_277`'s annex (130 numbered, 0 bare). |
| A-4.4 | Repeated named units (`Súmula CARF nº 1`…`nº 130`) are **not** a label-grammar rule but a document-level series detection: ≥3 whole-paragraph occurrences sharing a folded head word with strictly increasing numbers. This is what keeps `Lei nº 12.618` from ever parsing as a label. |
| A-4.5 | Hierarchy is inferred over the body **and each annex** (R-2), so the deliverable is a `HierarchyDoc`, not a bare tree. |
| A-4.6 | **No sample has a contiguous multi-level Word list**, so `ilvl` nesting cannot be discharged by a golden. A synthetic fixture is used instead — the A-1.3 precedent — and it earned its place immediately by catching a bug that dropped every nested item. |

## 4. Expanded goals

### 4.1 `src/lexml_nonstat/model/nodes.py` (new)

```python
@dataclass(frozen=True)
class Para:
    inlines: tuple[Inline, ...]
    kind: str = "prose"          # prose|quote|citation|field|omissis
    indent: int = 0
    source_indices: tuple[int, ...] = ()
    @property
    def text(self) -> str: ...

@dataclass(frozen=True)
class ListItem:
    inlines: tuple[Inline, ...]
    children: tuple["ListNode | Para", ...] = ()
    source_indices: tuple[int, ...] = ()

@dataclass(frozen=True)
class ListNode:
    ordered: bool
    items: tuple[ListItem, ...]
    @property
    def source_indices(self) -> tuple[int, ...]: ...

@dataclass(frozen=True)
class Table:
    rows: tuple[tuple[tuple[Inline, ...], ...], ...]
    source_indices: tuple[int, ...] = ()

@dataclass(frozen=True)
class Section:
    label: str | None
    heading: str | None
    level: int                   # 1-based
    kind: str
    body: tuple[Node, ...] = ()
    children: tuple["Section", ...] = ()
    evidence: Evidence = ...
    source_indices: tuple[int, ...] = ()
    @property
    def all_source_indices(self) -> tuple[int, ...]: ...   # incl. descendants
```

All carry `to_dict()` / `from_dict()` in the Cycle 1–3 house style (default-valued
fields omitted), so goldens stay readable.

### 4.2 `src/lexml_nonstat/hierarchy/labels.py`

```python
@dataclass(frozen=True)
class Label:
    raw: str                 # "2.3.1 -"
    kind: str                # numeric|roman|alpha|compound|named|artigo|paragrafo|unit
    value: tuple[int, ...]   # (2,3,1); roman/alpha reduced to an ordinal
    text: str                # remainder of the paragraph after the label
    separator: str | None    # ".", "-", ")", None
    depth: int               # len(value) for numeric; 1 otherwise
    unit_head: str | None    # folded head word for `unit`

def parse_label(text: str, *, unit_heads: frozenset[str] = frozenset()) -> Label | None
def roman_to_int(s: str) -> int | None
def alpha_to_int(s: str) -> int | None
def looks_like_heading(text: str) -> bool
```

Positives: `1.`, `2.1`, `2.3.1 -`, `I -`, `II.`, `XIV -`, `a)`, `c.`, `c. 1)`,

### 4.3 `src/lexml_nonstat/hierarchy/quotation.py`

```python
@dataclass(frozen=True)
class QuoteBands:
    body_indent: int
    quote_values: frozenset[int]
    rule: str                 # "none"|"deviation"|"declared"
    field: str                # "indent_effective"|"indent_direct"

@dataclass(frozen=True)
class QuotationAnalysis:
    bands: QuoteBands
    quoted: frozenset[int]        # block indices
    omissis: frozenset[int]
    citation_antecedent: frozenset[int]
    article_values: tuple[int, ...]
    article_monotonic: bool
    def is_quoted(self, index: int) -> bool

def analyse_quotation(paras, *, profile=None) -> QuotationAnalysis
def detect_quote_bands(paras) -> QuoteBands
def is_omissis(text: str) -> bool
def names_external_norm(text: str) -> bool
def is_monotonic_series(values, *, start_max=2, max_gap=3) -> bool
```

Band rules, in order:
1. **deviation** — values ≥ modal effective + 300 twips, covering ≥3 paragraphs.
2. **declared** — when the modal effective indent is *inherited* (majority of its
   paragraphs have `indent_direct is None`) and the modal **declared** indent is
   ≥300: quote band = declared values within ±64 of that mode. (A-4.1.)
3. **none**.

Per-paragraph verdict: quoted iff in the band, **or** opens with `"`/`“`, **or**
`is_omissis`, **or** (citation antecedent **and** the article series is
non-monotonic).

### 4.4 `src/lexml_nonstat/hierarchy/evidence.py`

```python
@dataclass(frozen=True)
class Evidence:
    signals: tuple[str, ...]     # e.g. ("style","outline")  ("label:numeric","series")
    score: float                 # 0..1
    def with_signal(self, name, weight) -> "Evidence"

@dataclass(frozen=True)
class DocSignals:
    n_blocks: int
    n_sections: int
    coverage: float              # blocks under some section / blocks
    label_kinds: tuple[str, ...]
    style_headings: int
    rejected: tuple[str, ...]    # why candidates were dropped — telemetry for 4b
    confidence: float
```

Weights: style/outline heading 0.9; validated label series 0.85; unit series 0.8;
isolated label with no series 0.25; conflict penalty 0.2. Document confidence is the
mean section score, damped by `min(1, n_sections/3)` — one lone section is never
high confidence. Threshold **0.5**; below it, flat fallback.

### 4.5 `src/lexml_nonstat/hierarchy/unify.py`

```python
@dataclass(frozen=True)
class Candidate:
    index: int; label: Label | None; style_level: int | None; quoted: bool

def collect_candidates(paras, analysis, *, unit_heads) -> tuple[Candidate, ...]
def detect_unit_series(paras) -> frozenset[str]           # A-4.4
def validate_numeric_series(values) -> bool               # A-4.2
def unify_levels(candidates) -> tuple[Assignment, ...]    # candidate -> depth, kind
def demote_numbered_containers(assignments) -> tuple[Assignment, ...]   # A-4.3
```

`unify_levels` maintains a stack of open label *tracks* (one per label kind/prefix).
A dotted numeric label is placed by prefix-matching an open parent (orphans rejected);
a new kind opens a deeper level; a return to a seen kind pops back to it. Depth never
increases by more than 1 between consecutive headings — enforced, not hoped for.
