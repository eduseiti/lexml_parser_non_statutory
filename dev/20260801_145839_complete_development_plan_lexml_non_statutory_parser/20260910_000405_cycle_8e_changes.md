# Cycle 8e — changes to already-delivered features

- **Cycle:** 8e (A-L.1 … A-L.9), plan §18
- **Date:** 2026-09-10
- **Spec:** [`20260910_000405_cycle_8e_spec.md`](20260910_000405_cycle_8e_spec.md)

The cycle is overwhelmingly **additive**: a new `refs/` subpackage, two new
golden kinds, four new matrix rows, six new test modules. **All 135
pre-existing goldens across the 9 pre-existing kinds are byte-identical**,
which was the cycle's first exit criterion and is asserted rather than
asserted-about.

What follows is everything that touched delivered code, in the order it
happened.

---

## Major changes

### M-1 — none

No change altered previously-delivered *output*. The one change that could
have, and was escalated, is recorded as **m-9** below: it was confined to the
reference path by construction and measured to leave every existing golden
byte-identical.

## Minor changes

### m-1 — `render_inlines` takes references and grows a nesting level

| Field | Content |
|---|---|
| What changed | `src/lexml_nonstat/render/common.py` — `render_inlines(parent, inlines, references=())` |
| Before → after | Nesting order was `a → b → i → sup → sub`; it is now `a → Remissao → b → i → sup → sub`. With `references=()` the function is byte-for-byte what Cycle 5 delivered — the no-reference case returns through a dedicated branch (`_render_runs`) so that equality is structural, not incidental |
| Why | A-L.2/A-L.3: `<Remissao>` is an inline element wrapping a character span, and `Inline` is the wrong unit for a citation that crosses runs |
| Blast radius | Every emitter, since all of them render paragraphs. Guarded by `test_no_references_renders_exactly_as_before` and by all 135 goldens |
| Plan impact | §5.1 gains the reference surface; recorded as A-L.2 |

The `a`/`Remissao` order was the user's decision of 2026-09-10, taken after
**both** directions were measured legal on both schemas and both generations
(matrix rows R3/R4). It extends the delivered order rather than inverting it.

### m-2 — `render_para` and `render_node` accept a linker

| Field | Content |
|---|---|
| What changed | `render/common.py` — `render_para(para, *, references=())`, `render_node(node, *, table_id, linker=None, context_urn=DEFAULT_CONTEXT_URN)` |
| Before → after | Both gained keyword-only parameters that default to the delivered behaviour |
| Why | A-L.3: references resolve **at render time**, from a `linker=` argument, and are never stored on `Para` — which is what leaves the `styled`, `hierarchy`, `metadata`, `segment` and `routing` goldens structurally untouched |
| Blast radius | Additive; every existing call site keeps its meaning |
| Plan impact | §3.1, §5.1–§5.3 (A-L.3) |

### m-3 — `resolve_references` and `_text_references` added

New public helper `resolve_references(para, linker, context_urn)` and its
plain-string sibling. Both are the *only* places a linker is consulted, and
both swallow every exception: `find_refs` is documented never to raise, but the
protocol is public and a third-party implementation might. A citation is not
worth a failed render.

### m-4 — the three emitters and `render_anexo` thread a linker

| Field | Content |
|---|---|
| What changed | `render/generico.py`, `render/generico_aninhado.py`, `render/norma.py`, `render/anexo.py` — `render_generico`, `render_generico_aninhado`, `render_norma`, `render_norma_checked`, `render_statutory`, `render_anexo`, the three `*_from_docx`, and the private helpers between them and `render_node` all gained `linker=None, context_urn=DEFAULT_CONTEXT_URN` |
| Before → after | Additive keyword-only parameters; `linker=None` reproduces the delivered output |
| Why | A-L.7 requires the flag to be *threaded*, not accepted and discarded — A-C.1's lesson, where `--referee` was built and then dropped on the whole unified CLI |
| Blast radius | All 32 `generico`/`generico-aninhado` goldens and both `norma` goldens; all byte-identical |
| Plan impact | §5.1–§5.3 |

Fanned out to a subagent, which reported one finding worth recording: the
statutory dataclasses (`Artigo`, `Caput`, `Paragrafo`, `Inciso`) hold plain
`str`, not `Para`. It was instructed **not** to restructure them, and did not;
`_paragraphs()` resolves references against the string directly instead. It
also escalated rather than fixing the collision recorded as **m-8**.

### m-5 — `front_region`, `back_region`, `_region`, `_region_element` thread a linker

| Field | Content |
|---|---|
| What changed | `render/common.py` — the four region functions gained `linker`/`context_urn`; new `_linked_paragraph` helper |
| Before → after | With `linker=None`, `_region_element` still delegates to Cycle 3's `agrupamento_block`, so there remains **one** implementation of the element shape for the delivered path. With a linker, it builds the same shape itself, resolving per paragraph |
| Why | **Measured**: 169 of the 379 references the linker can resolve — **45 %** — live in front/back matter, in 12 of 15 samples, and two samples (`ad_srf_22`, `adn_cosit_19`) are *nothing but* front and back matter and resolved **zero** references without this |
| Blast radius | Every `generico`/`generico-aninhado` render; all goldens byte-identical |
| Plan impact | §5.1; the deliverable list in §18 says "`<Remissao>` emission in the three emitters, via `render/common.py`", which this satisfies more completely than a body-only reading would |

**Escalated to the user before implementing** (2026-09-10), because it widens
the diff into delivered Cycle 3/5 code and changes what the linked goldens
contain. The user chose to thread it.

### m-6 — `tests/conftest.py` declares `xmlns:xlink` in `lexml_doc`

| Field | Content |
|---|---|
| What changed | `lexml_doc(inner)` now emits `<LexML xmlns=… xmlns:xlink=…>` |
| Before → after | An unused namespace declaration is added to every test document |
| Why | `Remissao` and `a` both carry `xlink:href`; a fragment using an undeclared prefix is not **parseable**, so a matrix row about the reference surface would fail on well-formedness before any schema saw it |
| Blast radius | Every test that builds a document through this helper |
| Plan impact | none |

Not assumed to be harmless — **measured**. All 32 existing row × schema pairs
were validated with and without the declaration before the change: `0`
differences.

### m-7 — `tests/conftest.py` gains `requires_linker`, `LINKER_FIXTURES`, `fixture_linker`

Additive, beside `requires_nested` and following it exactly: the skip reason is
the probe's **own diagnostic**, so a skipped run says whether the binary is
missing or present-and-broken.

| Field | Content |

### m-9 — pretty-printing suppressed inside a linked paragraph

| Field | Content |
|---|---|
| What changed | `render/common.py` — after emitting references, `render_inlines` sets `.text = ""` on the paragraph and on any `Remissao` whose content is entirely elements |
| Before → after | `<p>` with only element children was serialised indented, one child per line; it is now serialised inline |
| Why | **A defect this cycle's own conservation gate caught.** `pretty_print=True` indents an element whose `.text` is `None`, and only then. Splitting runs at a reference boundary can leave a `<p>` whose content is entirely elements — an all-bold paragraph carrying a citation becomes `<b>…(</b><Remissao><b>…</b></Remissao><b>)</b>` — and the printer then injected indentation that **survived reparsing as real text** |
| Blast radius | Confined to the reference path: the condition can only arise where a run was split. Measured — all 135 pre-existing goldens byte-identical after the change |
| Plan impact | none |

The measured damage was three spaces inside two `CARNE_LEAO` paragraphs:
`adotada (Lei 13709/2018)` became `adotada ( Lei 13709/2018 )`. The document
was **valid on both schemas** throughout. This is the A-6.4 failure mode
exactly, and it is worth stating what caught it: not the schema, not a word
multiset, but the **character** multiset A-L.4 requires. A word-level
comparison would have reported no difference at all.

The same condition exists latently in the delivered goldens — an all-bold
paragraph containing an `<a>` is already serialised indented — so this is a
pre-existing serialisation weakness that Cycle 8e made *reachable* rather than
introduced. Widening the fix to those paragraphs would move committed goldens
and is **not** done here; it is recorded as an open item.

## Changes considered and rejected

| # | Change | Why rejected |
|---|---|---|
| r-1 | Store `Reference`s on `Para`, resolving during model build | A-L.3 forbids it, and for a good reason: it would put linker output into the `styled`, `hierarchy`, `metadata`, `segment` and `routing` goldens, making five kinds depend on an external binary. Render-time resolution is what keeps them structurally untouched |
| r-2 | Pass each document's own URN as `--contexto` | **Measured** to resolve zero references on every one of the 15 samples, silently (§2.2 of the spec). This is amendment A-L.9 |
| r-3 | Retry with the fallback context when the own-URN attempt returns nothing | "Zero references" is ambiguous — a paragraph that genuinely cites nothing is indistinguishable from a rejected context — so the retry would double subprocess traffic to learn nothing. Offered to the user; the user chose the constant |
| r-4 | Normalise the cited text to match the URN | `hierarchy/quotation.py` already ratified the opposite: "the norm comes back **as written**, never normalised — a document's own spelling of a law is the citable fact". The URN travels *beside* the text, not instead of it |
| r-5 | Use `RemissaoMultipla` for paragraphs with several citations | It requires `xml:base` (`lexml-base.xsd:770-777`), which would make the paragraph's references relative to a base the document does not otherwise have. A-L.2 rules it out; measurement gave no reason to revisit |
| r-6 | Widen `Remissao` emission to table cells and list items | Deliberately deferred (spec N-5). The extractors were made read-through *everywhere* regardless, so widening later moves no golden and needs no re-measurement |
| r-7 | Fix the pretty-print indentation for **all** paragraphs, not just linked ones | It is a real latent weakness, but fixing it would rewrite committed `generico` goldens for a cosmetic serialisation change unrelated to this cycle's goal — precisely the unreviewable diff §9.4 exists to prevent. Recorded as an open item instead |
| r-8 | Make `--linker=auto` an error when no binary is present | It would break A-R.9 and the bare-checkout exit criterion. `auto` means "use it if it is here" |
| r-9 | Have `build_linker` raise on any unknown mode string | It must accept a **path**, so an unknown string is a path by construction. The validation belongs in the CLI, where a typo can be told apart from a path — and that is where it was put |
